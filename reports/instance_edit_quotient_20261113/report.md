# 实例编辑方向与原生密钥恢复

已经实现并验证“登记最终图 → 实例编辑方向校正 → 128位密钥恢复 → 解封原生材料 → 原生水印检测”的链路。八方向版本在三组投影下恢复473–477/500个合法查询，同提示词不同实例均0/50；原生GS检测已实际消费恢复出的验证材料。

## 可执行机制

每个来源登记原图及四类官方随机处理各两张图片。把登记特征分解为沿参考方向的分量和垂直的编辑分量，再以SVD得到该实例的四维或八维编辑空间。查询和登记特征都先投影到其正交补，再量化为1023位码，使用BCH(1023,133,d≥255)恢复128位密钥。恢复时只接收查询、经过认证的辅助记录、全局投影和提供方秘密，不接收原图特征。

辅助记录保存float16编辑基；读回后重新正交化，登记和恢复使用相同序列化精度。四方向使用各类编辑的均值，八方向使用全部登记视图。量化前消除该图的编辑漂移，使固定纠错半径集中处理剩余变化。原生载体与原生攻击代码保持冻结。

切空间消除本身有明确先例：[Simard、LeCun、Denker，NIPS1992](https://papers.nips.cc/paper_files/paper/1992/hash/26408ffa703a72e8ac0117e74ad46f33-Abstract.html)。本轮检验它能否形成有用的实例恢复区域，并给出了真正的密钥恢复实现。新增论文贡献还需体现在稳定的区域分离、协议性质或成本收益上。

## 协议与分母

本轮复用首轮2110图的特征与110个来源，重新执行三组投影、四方法的14760次实际解码；基础码检查合计12次。100个空间GS来源按50校准/50评估分组，另10个PGID-GS来源用于完整Imprint迁移。每个评估来源含干净图、九种处理和同提示词独立实例。全部来源来自开发数据；本轮在前两次结果之后确定，独立确认集尚待执行。

[协议](../../protocols/instance_edit_quotient_20261113.json)、[执行协议](../../protocols/instance_edit_quotient_20261113_execution.json)、[特征来源](features_complete.json)和[完整评分](scores.json)记录哈希、参数及分条件结果。处理图查询使用不同于登记的随机种子；亮度、JPEG、模糊、中值和缩放未进入登记。100个空间GS来源的处理图本轮测内容恢复，其全部原生反演尚未执行；PGID-GS的100个合法查询有完整的原生检测对照。

八方向的收益主要来自亮度和裁剪。第0组中，亮度由29/50升到40/50，裁剪由46/50升到49/50；随机丢弃由41/50降到38/50。处理方向消除与再次按编辑方差选位叠加后下降，说明两者的误差分配并不相同。具体数字按条件完整保留。

所有方法使用相同登记图片和来源拆分，阈值由校准侧全部合法查询决定。下表为90%校准目标下的评估结果；分母包含干净图。连续切空间SSCD使用与密钥恢复完全相同的实例变换。

95%校准目标下，所有实际恢复版本的最大校准通过率仍不足95%；多模板SSCD为476/500、不同实例0/50，八方向连续SSCD为480/500、0/50。最大恢复能力表与95%校准点分别报告。

[按来源配对的bootstrap](source_uncertainty.json)以50个来源为抽样单位，每个来源保留10个合法查询，共10000次重采样。90%目标下，八方向实际恢复相对int8多模板SSCD的差值为+1.4、+2.4、+1.8个百分点，对应95%描述性区间为[-0.6,3.4]、[0.4,4.4]、[-0.2,3.8]个百分点。结果尚未在各投影和独立数据上形成稳定优势。

## 原生检测、成本与实现范围

[原生验证](native_key_verification.json)对第0组的100张空间GS干净图、100张PGID-GS合法查询、30张Imprint检查点图再执行920次密钥恢复。196次不同的原作者检测调用直接使用恢复出的材料，BA全部与缓存反演的原始记录一致；空间GS干净图100/100，四方向版本PGID-GS合法96/100、最终Imprint0/10。多个方法恢复同一材料时复用该次新原生检测。扩散潜变量来自既有哈希核验缓存。

第0组每次恢复平均耗时约9–11ms，不含SSCD和扩散反演。固定版紧凑辅助字段1216字节，四方向5312字节，八方向9408字节；标识配置和原生材料封装另计。空间GS实际JSON记录分别4781、10355、15815字节。九模板int8为4608字节，float32为18432字节；完整系统两侧均需计入原生验证材料。当前八方向版本在存储上大于int8多模板对照。

[TR/PRC材料序列化检查](native_state_serialization_checks.json)已通过原作者CPU检测往返。后续[跨载体协议](../../protocols/recovered_carrier_transfer_20261113.json)冻结本轮四种方法、三组投影和GS校准阈值，在TR/PRC完整Imprint结束后执行280次原生反演、3360次实际恢复。TR/PRC的完整图像结果在该任务完成后另行报告，当前不填入成绩表。

## 当前研究落点

实际恢复链路已具备，实例方向校正也产生了可定位的收益与代价。现有结果支持继续研究如何保留实例差异并覆盖编辑的尾部误差；本轮的切空间投影与既有可靠选位属于需要超过的具体方法对照。新增密码学原语、1e-6经验误报率和全面优于SemBind/PGID/SEAL均不在本轮已建立的结论中。
