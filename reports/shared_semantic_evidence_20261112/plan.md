# 共享语义比特的置信证据：防御假设与完整验证

## 失败分析与研究问题

分位载体的240条潜变量已在249服务器完成误差分解，见[逐条记录](../conditional_quantile_pilot_20261112/failure_decomposition.json)。候选的幅值通道误码率0.425372，符号通道0.343854；只用幅值观测接受23/60，只用符号观测接受51/60，合并后48/60。登记语义码诊断提升到55/60仍不及本轮full的60/60登记码诊断。故载体信道和语义漂移都造成损失，不能继续靠增加幅值载荷或提高重复数来推断收益。

本轮使用已有full载体，研究问题变为：反演观测和语义查询各自不可靠时，应怎样组合证据，使重复载荷降低信道噪声，却不把一次不确定的语义判断当成16个独立内容证据？

## 原始文献与创新边界

- [SemBind §3.1–3.3](https://arxiv.org/html/2601.20310v1)使用logits训练、二值码推理，辅助图语义掩码在查询端由二值码重建。其对比学习与比特一致性训练已经存在，单纯再加一致性损失不能作为本项目创新。
- [Gaussian Shading++ §IV-C](https://arxiv.org/html/2504.15026v2)已有高斯信道后验与载荷软译码。因此载荷加权不是新方法，也不能把本项目的译码对照称为GS++完整原生复现。
- [On Calibration of Modern Neural Networks](https://proceedings.mlr.press/v70/guo17a.html)，Guo、Pleiss、Sun、Weinberger，ICML2017，PMLR70:1321–1330，已有单参数温度缩放。置信度校准不是新贡献。
- 本项目先前的条件内容似然也已按语义比特边缘化；共享分组或证据上界本身不能重新包装为首创。它使用固定的平均语义翻转率，未建模查询logit提供的逐比特语义可靠性。此次必须优于这一直接对照才有继续研究的依据。

当前候选把查询端语义不确定性放入共享语义变量的似然中。若实验只说明某种通用软加权有效，而不能显示共享变量结构和语义可靠性各自的作用，则不足以形成独立论文贡献。检索未找到完全一致表述，不等于已经证明新颖性。

## 模型与可证伪预测

每个1024位语义码比特h_k对应16个载荷坐标。假设完整反演坐标服从工作模型y_i = a z_i + e_i，其中e为方差v的高斯噪声，则原符号后验均值为

`r_i = erf(a y_i / sqrt(2 v (a²+v)))`。

这是GS++已有后验思路的增益扩展，a与v只用拟合来源估计。给定待验证身份的密文位c_i，将r_i乘以`1-2c_i`，按密钥置换把16个坐标还原为一个语义组：

`u_k = tanh(sum_{i in group(k)} atanh(r_i (1-2c_i))))`。

查询图语义网络logit为l_k，通过拟合来源的正温度T定义`q_k = tanh(l_k/(2T))`。主分数为

`S = mean_k log(1 + u_k q_k)`。

该比值比较“语义变量由查询证据约束”和“语义变量与查询无关”的工作假设。查询置信度为零时该位贡献为零；每位贡献最多log2，增加重复观测只使u_k接近其极限，不将q_k复制成独立证据。由于反演误差和语义位之间存在相关性，这里是复合似然分数，不是校准p值、真实FPR或密码安全证明。

两个可证伪预测：其一，logit幅度应在未参与拟合的来源上提供比固定语义翻转率更有用的信息；其二，在相同生成和反演条件下，按语义组融合应优于把每个载荷坐标独立软处理的对照，同时不能增加伪造接受。任一核心对照未胜出，都应收缩方法主张。

## 公平对照与信息权限

| 规则 | 内容与载荷处理 | 工作点 |
|---|---|---|
| default_ba | 原硬掩码、多数译码 | 保持BA>181/256 |
| ba | 同一硬判定 | 独立校准来源上95%目标 |
| latent_soft_ba | 高斯载荷软译码，语义仍硬判定 | 同一校准策略 |
| coordinate_soft_ba | 载荷与查询语义软值逐坐标融合 | 同一校准策略 |
| group_constant | 共享语义组、固定平均语义翻转率 | 同一校准策略 |
| group_query | 共享语义组、查询logit可靠性 | 同一校准策略，主候选 |

全部规则共享新生成的同一张参考图、同一查询和完整反演。测试推理只使用查询图logit/二值码、反演潜变量与待验证身份密钥，不使用登记语义码或原图。目标身份消息可用于验证比较，权限与原项目相同。没有训练新攻击，也不向基线生成进程提供私有验证参数。

## 数据隔离与冻结

拟合：此前共享锚实验中的6个full来源，60条真实查询。校准：此前分位实验中的另外6个full来源，60条查询。两者都是已使用的开发来源，不声称独立确认。只重新提取官方网络logits，逐位验证与保存的官方二值码一致；已有完整50/100步反演无需重复计算。

温度只拟合一个正参数，logT在[-8,8]，bounded minimize_scalar，xatol1e-8，最多500次迭代。载荷模型全局a、v由拟合来源的真实初始噪声与完整反演坐标估计。固定语义错误率也只从拟合来源估计。各校准规则采用60条分数中第4小值，比较为>=，目标至少57/60；并列可能使实际接受更多。校准目标不等于测试TPR，必须报告实际计数。

12个新的提示词、身份和预览种子在协议中提前固定。参数与门限生成后写入冻结哈希，随后才开始新来源的图像生成。不得用测试结果、错误身份或伪造样本调参。

## 完整实验任务链

1. 三个GPU分片重新提取120张开发查询的官方logits，完成拟合、校准和模型冻结。
2. 生成12张辅助图和12张full参考图；干净加9种官方GS失真共120条完整反演。
3. 独立审计原BA、图像/码/潜变量哈希与完整组合；评估全部六种规则，另做1320个错误身份判决。
4. 无论真实侧结果如何，完成12个原版CVPR2025 Imprint任务，每任务151次更新、完整50步代理反演、全部16个检查点。四张固定公共封面循环使用。
5. 对192个检查点、12张参考、12张封面完成216次完整验证，自动分析全部规则。总计336次新完整反演；所有生成/反演50步，解码器优化100步，float32。

所有工作在249，只用空闲GPU7、5、4，最多三张。子进程退出事件驱动后续阶段，不持续轮询。所有负结果保留；不存在根据检查点或来源选取最好结果。

## 验证与结论门槛

服务器上的24组数值检查通过，独立概率域实现与主实现共48次比较最大差异约3.8e-12，包含零语义置信度、相反语义、证据上界、原BA等价性等不变量。真实测试主分数和固定语义对照也逐条通过独立概率域实现复核。

只有主候选在实际真实接受上不低于直接对照，同时不增加最终伪造与错误身份接受，并出现实质严格改善，才考虑更大来源确认。这只是开发阶段的筛选条件，不是统计显著性或SOTA判定。12个新来源、四张重复封面和相关错误身份判决不能证明极低FPR；还缺大规模自然负例、更多已发表基线和原生防御同条件比较。
