# 重复观测二阶矩：防御统计量开发筛选

在249服务器上，对既有潜变量、查询语义码和完整已发表Imprint输出执行新的CPU评分实验。此次没有重新生成图片、执行反演或运行攻击；它是已消耗开发资产上的机制筛选，不是新模型实验或独立确认。

## 机制假设

SemBind全掩码载体中，每个语义位有16个置换后的观测。用声明身份的密文去除身份符号、逆置换，再与查询语义码比较，得到残差符号r。令A为全部符号的平均，B为同一语义组内不同重复位置乘积的平均。在独立、同质的二进制翻转信道下：

```
E[A] = (1 - 2d)(1 - 2e)
E[B] = (1 - 2e)^2
```

d为语义不一致率，e为物理信道翻转率。A/sqrt(B)的目标是消除信道衰减；这个总体矩恒等式不意味着有限样本比值无偏。主候选减去固定2.576倍影响函数标准误作为稳定性惩罚，B非正时拒绝。该惩罚不具有实际扩散潜变量上的置信覆盖保证。组间相关、异方差和语义相关信道均可能破坏解释。

校准使用分位实验中full组的六个来源、60条合法查询。各评分器均取校准分数第四小值作为95%目标门限，随后在共享语义实验的12个开发来源上评分。默认BA保持 > 181/256。没有使用伪造结果拟合阈值，也没有重新调节门限。
