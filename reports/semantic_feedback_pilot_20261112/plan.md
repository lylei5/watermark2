# 固定三轮语义反馈嵌入：机制验证协议

## 研究问题与证据

上一轮共享语义证据的120条真实查询已经完成完整反演并独立复核。默认BA接受107/120，候选85/120；干净图分别12/12与9/12。冻结温度的语义对数损失从校准集0.23837上升至新来源0.38289。使用真实注册信息的事后诊断同时替换信道和温度参数也只恢复到90/120。这表明当前候选的失败不能简单归结为单一参数估计。该测试集已消耗，不用于重新选阈值。完整既有Imprint评估仍按原协议完成。

下一项检验生成端能否降低“绑定码与最终生成图不一致”。不是降低门限，而是固定密文、幅值和提示词，让上一轮生成图的官方语义码成为下一轮绑定码。只有机制收益、真实检出与保真共同成立，才扩展伪造侧验证。

## 方法与对照

令H为发布的SemBind语义网络，G为固定提示词下完整50步生成器，E(c,h;a)为现有全容量符号嵌入。c为同一身份的加密重复载荷，a为固定幅值。由一张独立辅助图得到h0，固定执行：

```
x1 = G(E(c,h0;a)); h1 = H(x1)
x2 = G(E(c,h1;a)); h2 = H(x2)
x3 = G(E(c,h2;a)); h3 = H(x3)
```

| 组别 | 最终图 | 实际绑定码 | 单独部署的完整生成次数 |
|---|---|---|---:|
| full | x1 | h0 | 2：辅助图与水印图 |
| feedback | x3 | h2 | 4：辅助图与三轮水印图 |
| consensus | 三张独立辅助图逐位多数码生成的水印图 | 多数码 | 4：三张辅助图与水印图 |

全部保留256位消息、64次重复、16384个空间符号坐标。反馈轮次与三组共享身份、幅值及提示词。固定采用第三轮，不提前停止，不按检出分数或收敛情况选图。保存每轮输入码、输出码、初始载体和图片，报告振荡及二周期。实验复用共享的第一张辅助图与第一轮图，实际每来源7次生成，共42次；这不改变单独部署预算。

解码始终为原硬多数译码与BA > 181/256，不加入新评分器或后验调参。此处full是使用官方语义网络的项目载体适配器，不能称为完整原生SemBind复现。

## 样本与完整预算

六个此前未使用的中性提示词、六组新私有身份，三组配对。每组每来源包含干净图和Gaussian Shading官方九条件，共180次完整查询验证；对其余五个身份分别验证，共900个错误身份对。提示词、随机种子、模型及官方组件哈希见[冻结协议](../../protocols/semantic_feedback_pilot_20261112.json)。私有密钥仅在服务器保存，Git只保存其文件摘要。

每次生成50步；每次验证使用发布的DPM链、完整100步解码器优化与50步反演。GPU仅7、5、4，最多三张且必须空闲。安装源为清华；本轮直接复用现有服务器环境。

## 预先固定的推进门槛

以下七项必须同时满足：

1. feedback平均绑定误差比full至少低0.02。
2. feedback平均绑定误差不高于相同生成次数的consensus。
3. feedback真实接受数至少比full多1，且不低于consensus。
4. 六张feedback干净图全部接受。
5. 至少4/6来源第三轮绑定误差严格低于第一轮。
6. feedback相对第一张辅助图的平均LPIPS不超过full加0.05。
7. feedback错误身份接受数不超过full与consensus中的较小者，各组分母300。

这是六来源可行性筛选，不是统计显著性或论文级优越性判定。所有结果均保留。若任一项失败，完成独立复核和负结果分析，不扩大该候选的伪造评估。

全部通过时，自动执行18个未修改CVPR2025 Imprint案例，覆盖六来源全部三组；每例151次更新、全部16检查点，连同原图与封面共324次完整验证。主要端点固定为第151次更新，禁止最优检查点选择。第一阶段与扩展合计最多504次完整反演。原版攻击源码、配置和实现一致性检查保持不变。

## 独立验证与接续

服务器上的载体单元检查通过16身份、48次往返：改变137个语义位恰好改变2192个载体符号，幅值不变。扩展后的独立审计器重新核算此前240条查询与24张参考图，全部结果一致。见[unit_checks.json](unit_checks.json)与[audit_regression.json](audit_regression.json)。这些检查只证明实现不变量，不证明反馈收敛或防御收益。

运行时独立重建18个反馈载体，核对全部输入输出、图片哈希、共识码、180个身份分数与900个错误身份分数；另行重算绑定误差和LPIPS。协调器通过内核进程退出事件等待上一轮完整120条真实和216条伪造记录审核通过，然后才申请空闲GPU。无持续轮询。启动回执另行记录；在回执存在前本协议只代表已冻结的安排。

## 文献定位与限制

[SemBind，ICML2026](https://proceedings.mlr.press/v306/zhang26hj.html)提供语义内容绑定及发布的语义网络；本实验复用其组件，不能将其作为新贡献。[Gaussian Shading++](https://arxiv.org/html/2504.15026v2)已有软证据译码，因此上一轮软判决本身也不是新颖性。[Latents-Inv，IJCAI2026](https://ijcai.org/proceedings/2026/75)从可逆训练与信息冗余处理水印验证，属于需要进一步做原生对照的相关防御。[SEAL，ICCV2025](https://openaccess.thecvf.com/content/ICCV2025/papers/Arabi_SEAL_Semantic_Aware_Image_Watermarking_ICCV_2025_paper.pdf)也是语义感知水印先例。

通用迭代与固定点思想不是新概念。待证贡献限定为：固定全容量载体的输出反馈是否能比相同生成预算的辅助码共识更有效地减少绑定失配，并保留实际防御性能。尚未证明这一组合具有可发表的新颖性。

从第二轮开始，语义码经上一轮生成图依赖密文。即使逐坐标幅值保持不变，也不能沿用单次独立掩码的联合高斯分布论证；不宣称隐蔽性或安全证明。没有收敛保证。LPIPS仅衡量与辅助预览的配对距离，不代表FID、总体图像质量或分布保持。四张重复封面及有限错误身份对不能支持极低总体FPR。若试验成功，仍需更大独立来源、原生防御比较、分布与质量评估。
