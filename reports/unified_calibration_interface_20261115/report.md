# PRC连续分数与经验校准接口验收

**235次判定比较，导出分数与未修改的作者PRC Detect结果完全一致，差异0。** 该CPU验收在249执行，覆盖40份自然开发图反演产物、6份原生正例潜变量和1份零后验边界输入；每份输入使用0.9、0.5、0.01、0.001、1e-6五个名义水平。

[逐输入证据](complete.json)保存原函数判定、导出分数判定、源码哈希和输入协议哈希。该结果只验证评分接口，不是自然图上的经验FPR，也没有执行攻击。

导出的是作者Detect判据的同一统计量：原对数和减去其中心项，再除以原方差项的平方根。阈值对应 `sqrt(log(1/nominal_fpr))`。参数名中的FPR不保证自然图上达到这个水平，仍须在独立自然图上校准和验证。

[校准实现](../../scripts/defense/empirical_calibration.py)采用固定方向的上尾规则，保留严格边界和所有并列值，不随机拆散并列分数。9组不同样本量/目标水平的离散检查全部满足校准集允许的误报数。PRC原生的Detect OR Decode通过固定接受分支表示；如果该分支已经超过误报预算，返回“不可达”，不删除Decode分支或更换规则。该分支逻辑通过边界检查，真实Decode分支的自然图FPR仍待实测。

比例区间采用95% Clopper–Pearson区间，来源单位由上游固定；相关的候选或多个检查点不能当作独立来源。一个直接的容量提醒：0/100的95%区间上限仍为3.62%，不能支持已经达到0.1%自然图FPR的结论。

下一项验收是共同载体下GS/TR/PRC的最终评分连接，以及大规模独立自然图校准。本次没有替代这些尚未完成的步骤。
