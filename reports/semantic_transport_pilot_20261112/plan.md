# 条件高斯传输：完整码字下的语义耦合

## 机制与研究命题

本实验研究辅助图与水印图的随机性耦合。令辅助图初始潜变量为Z，语义码为H(G(Z))，与身份密文结合后得到每个坐标的目标符号T_i∈{0,1}。采用逐坐标映射：

```
Y_i = Φ⁻¹((Φ(Z_i) + T_i) / 2)
```

Φ是标准正态CDF。对于每个目标符号，这个单调分位映射把标准高斯变量传输到相应的正或负半高斯区域。全部16384个符号都满足原始目标，每个256位身份位保留64/64的初始匹配。验证时使用原始SemBind项目适配器的语义掩码、硬多数译码与BA > 181/256，不引入新的检测器、训练网络或反馈轮次。

研究问题是：保持完整目标码字及条件载体分布时，优化与登记辅助图的潜变量对应关系，能否减少写入造成的语义漂移，并保留合法检测及已发表基线下的防御效果？

## 可证明部分及边界

在新鲜、独立、均匀的理想密文C模型下，T=C XOR H(G(Z))在给定Z后仍均匀，因此T与整个Z独立。给定T，各坐标的上述映射把独立标准高斯变量映射为独立的目标半高斯变量；对均匀T取平均，Y恢复联合标准高斯分布。真实ChaCha依赖密码学假设；该论证不是固定密钥条件高斯、任意nonce复用安全性或实际低FPR证明。

这里的联合高斯指Y内部各坐标的联合分布。Z与Y之间的相关性是内容保持机制的一部分；不声称公开辅助图与水印图构成的配对观测具有独立性或不可区分性。

对固定T，标准正态源与指定半正态目标之间的单调分位耦合最小化期望平方运输距离。这是经典一维最优传输事实；各坐标的平方代价相加，逐坐标映射给出这两个乘积分布之间的平方代价最优耦合。该最优性针对**指定条件分布之间的期望潜变量距离**，不声称逐图语义最优、图像质量最优或所有内容绑定系统的全局最优。

理想独立加性测量信道中，输出仍是全部目标符号正确的独立半高斯载体，因而具有与独立采样相同的无条件译码统计。真实反演误差依赖生成内容，这个理想统计结论不能代替模型验证。

## 配对对照与预算

| 组别 | 操作 | 检验因素 |
|---|---|---|
| full | 原项目SemBind独立半正态幅值、完整符号码字 | 现有适配器基线 |
| saturated | 复用辅助潜变量绝对值并写入完整目标符号 | 仅共享幅值是否足够 |
| transport，主候选 | 上述单调条件高斯映射 | 登记到完整码字的对应关系 |
| shuffled_transport | 将transport输出在相同目标符号位置之间固定随机重排 | 精确保留各符号组幅值多重集及目标码字，打乱与辅助坐标的对应关系 |

六个新来源，四组配对，干净图加九项Gaussian Shading官方条件，共240次完整验证、1200次错误身份判决。全部生成和反演50步，解码器优化100步。单组部署均为辅助图与水印图两次生成；共享辅助图后的实际生成总数为30。仅使用249的空闲GPU7、5、4，按UUID绑定，最多三卡，排除GPU6。

推进完整Imprint的冻结门槛：主候选合法接受不少于全部三个对照；干净图6/6；平均绑定差异比saturated至少低0.02且不高于shuffled_transport；辅助图LPIPS比saturated至少低0.05；错误身份接受不高于任一对照。全部满足才执行四组共24个未修改CVPR2025 Imprint案例，每例151次更新与16个固定检查点，共432条完整验证。失败时完整报告240条合法查询，伪造分支标记为未运行。

六来源是机制筛选。full为发布语义组件上的项目适配器，尚非完整原生SemBind复现。LPIPS是对登记预览的配对保真指标；240条条件查询不等于240个独立来源。所有失败与原始分母保留，不在该批结果上调整方法后宣称独立确认。

## 实现检查与查新边界

249上的实现检查覆盖64次完整身份往返、16384位全部目标匹配、稳定CDF实现与直接分位式的一致性、中央区间逆映射、同符号重排幅值多重集不变，以及重排不降低对应关系的平方代价。代码对有限精度下非有限数或符号丢失显式报错。Monte Carlo矩仅为实现诊断，不承担分布证明。

[Gaussian Shading](https://arxiv.org/abs/2404.04956)已有等概率高斯区域采样，[SemBind](https://proceedings.mlr.press/v306/zhang26hj.html)已有语义调制，[Mathon等，TIP2014](https://doi.org/10.1109/TIP.2014.2305873)已有最优传输降低自然水印失真。因此逆CDF、最优传输和内容绑定均不是单独新贡献。待证的具体贡献是：利用目标符号区域内的分布自由度，构造与生成端登记对象耦合的完整码字，在不消耗初始译码余量的情况下改善实际语义认证。新颖性及优越性仍需查新和实验证据，不能凭公式提前认定。

本轮所有攻击继续限于已发表的固定基线；辅助的高斯信道计算是数学模型分析，未生成新的图像攻击。

## 原始公式的先行工作核对

已核对Mathon等TIP2014论文的[作者稿全文](https://scispace.com/pdf/optimal-transport-for-secure-spread-spectrum-watermarking-of-1831ieowih.pdf)（HAL标识hal-00940754v2）。其式(17)–(19)给出正半高斯分位传输，式(22)通过输入和输出的符号对称得到任意目标符号。标准化方差并统一符号约定后，与本实验的逐坐标公式相同；最优性也已在该文证明。因此，本轮应定位为**已有传输映射对扩散语义登记问题的机制检验**，不能把映射、平方代价最优性或完整目标符号作为新算法贡献。即使冻结实验通过，也不足以单独确立可发表的新颖性。

[PPGS期刊记录](https://www.sciencedirect.com/science/article/pii/S0957417425044379)另外报告按载荷比例进行截断高斯采样及生成端软引导。当前可核对到出版社摘要，尚未取得全文来排除实现细节重合；不以摘要缺少辅助图耦合描述作为首创性证据。
