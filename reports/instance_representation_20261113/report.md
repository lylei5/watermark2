# 发布实例表征诊断

固定100个已有开发提示词，对比 SemBind 码、DINOv2 连续特征和 SSCD 拷贝描述子。输入、模型、源码、提示词族拆分及阈值选择规则见[冻结协议](../../protocols/instance_representation_20261113_v2.json)。机制和相关工作见[研究设计](../../docs/INSTANCE_BINDING_RESEARCH.md)。

每个来源包含辅助图、同提示词独立seed图、原GS图、GS-S最终图，以及最终图的九种独立GS官方处理，共1300张输入/表征。全部推理与统计在249执行，GPU7；DINO/SemBind和SSCD两次提取均已完成。

## 主要结果

每种配置在50个校准提示词的450个处理图上选取至少95%保留率对应的最小距离阈值。下表来自另外50个提示词，COCO和SDP各25个。同提示词不同seed图是实例匹配负例。

| 表征 | 参考图 | 干净最终图匹配 | 处理图保留 | 不同实例误匹配 |
|---|---|---:|---:|---:|
| SemBind 1024位 | 最终图 | 50/50 | 420/450（93.3%） | 42/50（84%） |
| DINOv2-giant连续特征 | 最终图 | 50/50 | 412/450（91.6%） | 32/50（64%） |
| SSCD disc_mixup | 最终图 | 50/50 | 428/450（95.1%） | 1/50（2%） |
| SemBind 1024位 | 辅助图 | 49/50 | 426/450（94.7%） | 48/50（96%） |
| DINOv2-giant连续特征 | 辅助图 | 46/50 | 400/450（88.9%） | 47/50（94%） |
| SSCD disc_mixup | 辅助图 | 47/50 | 406/450（90.2%） | 49/50（98%） |

SSCD最终图参考的阈值为`1-cosine <= 0.6199655532836914`。评估侧保留率的来源聚类bootstrap95%区间为[93.11%,96.89%]。1/50实例误匹配的Clopper–Pearson95%区间为[0.051%,10.647%]，该样本量用于路线筛选，下一步需要更多实例和完整水印认证。

阈值只在校准侧选择，各配置的评估侧合法保留率有所不同；这是预固定校准目标下的表征比较，尚未完成各防御的相同绝对合法检出率比较。不同实例误匹配属于内容门控结果，攻击接受和自然图水印误报将在完整认证中单独测量。

## SSCD最终图参考的失真分解

| GS官方条件 | 保留 |
|---|---:|
| random_crop_ratio=0.6 | 50/50 |
| random_drop_ratio=0.8 | 34/50 |
| brightness_factor=6 | 44/50 |
| jpeg_ratio=25 | 50/50 |
| gaussian_blur_r=4 | 50/50 |
| gaussian_std=0.05 | 50/50 |
| median_blur_k=7 | 50/50 |
| sp_prob=0.05 | 50/50 |
| resize_ratio=0.25 | 50/50 |

22个未保留处理图集中在区域置黑和亮度随机变化。这里的官方crop是在原画布中保留局部、其余置黑；drop将0.8倍边长的区域置黑。亮度6调用ColorJitter，具体倍率随机；gaussian_std沿用原函数的uint8转换与加法。原函数及参数逐字保留，结果适用于这些实际算子。

COCO/SDP处理图分别保留215/225、213/225；实例误匹配分别0/25、1/25。注册最终图时，辅助图误匹配1/50、另一个原GS输出误匹配3/50，也低于SemBind码对应的46/50、43/50。

## 机制判断

同一SSCD描述子从最终图参考改成辅助图参考，实例误匹配由1/50升到49/50，显示辅助图与最终发布实例的错位足以破坏实例绑定。最终图参考下，DINO连续特征与SemBind码仍有32/50、42/50的实例误匹配，成熟拷贝描述子能将其降到1/50。因此后续优先研究最终实例的恢复区域与编码，保留原生载体。

SSCD作为已有方法承担强对照。下一步冻结该阈值，接入本轮新执行的TR/PRC原生载体与完整Imprint产物，评价`原生检测 AND 实例距离`，同时研究二值码的恢复预算。
