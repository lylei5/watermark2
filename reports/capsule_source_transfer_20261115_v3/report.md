# 前向密钥恢复的100实例迁移验证

固定开发阈值后，前向恢复在1000张合法图上通过894张，同提示词不同实例通过0/100。单参考SSCD对应899/1000、0/100。当前方法在这批来源上保持了实例区分，合法覆盖尚未超过SSCD；主要损失来自强亮度下的观测不足和噪声下的预测残差。

## 实际执行范围

使用100个既有SemBind-bound登记实例，每例包括原图和九种原作者处理，共1000张合法图；另有same、aux、gs三类关联实例，共300张。100张登记像素彼此不同，与前一轮30张登记图也无像素重叠。这批资产曾用于早期表征研究，因此这里称为来源迁移验证，不称为全项目未见数据。

主设置及恒等算子消融沿用前一轮GS90%校准阈值，没有在这批图上修改方法或冻结阈值。2600次查询解码中，2042次准确返回密钥、1803次通过阈值并实际解封记录；另有100次登记密钥核验。解封载荷为登记标识和参考像素哈希，本轮不新增原生水印检测或攻击输出。完整攻击及317次原生检测见[前一轮报告](../transported_capsule_observability_20261115/report.md)。

SSCD、CopyNCE描述子与作者配对匹配器全部重新推理，分别处理1300张图，匹配器执行1300个配对。恢复与强对照逐张核对同一像素。SSCD采用原始单图批量，1300个特征与已核验缓存最大差为0。总耗时210.96秒，模型使用当时空闲的GPU7，恢复计算在249 CPU执行。

## 固定阈值迁移

| 方法 | 合法图 / 1000 | 其中处理图 / 900 | 同提示词不同实例 / 100 |
|---|---:|---:|---:|
| 前向密钥恢复 | 894 | 794 | 0 |
| 恒等算子消融 | 909 | 809 | 0 |
| SSCD单参考 | 899 | 799 | 0 |
| CopyNCE描述子 | 912 | 812 | 8 |
| CopyNCE匹配器 | 867 | 854 | 0 |

这些工作点均来自相同的旧GS合法校准数据，但迁移后的合法通过数不同，不能按最后一列直接排名。CopyNCE匹配器在此阈值下原图为13/100，处理图为854/900；原图全部保留在分母中，原始分数见逐样本文件。

[三张原图自配对复核](matcher_self_pair_audit.json)重新执行作者匹配器：单图与13图连续批量的最大分数差7.57e-6，13图结果与验收运行一致。三张自配对的预测分别约0.356、0.899、0.238；保留作者原始输出，没有增加“相同文件必通过”的特殊逻辑。

在描述性共同工作点上，把对照调到与主设置相同的894/1000合法通过数，same实例接受分别为：主设置0/100，SSCD0/100，CopyNCE描述子1/100，CopyNCE匹配器0/100，直接参考前向残差0/100，原始像素残差0/100。包含两个设置、三个来源分组、三类关联实例和五个对照的90项比较均匹配了准确合法通过数；74项相同、16项候选更低。各比较并非独立实验，不能把次数当作统计显著性。

## 失败在哪里

| 合法条件 | 准确恢复密钥 / 100 | 通过残差并解封 / 100 |
|---|---:|---:|
| 原图 | 100 | 100 |
| 保留坐标的裁剪置黑 | 100 | 98 |
| 区域丢弃 | 93 | 91 |
| 强亮度 | 70 | 70 |
| JPEG | 100 | 100 |
| 高斯模糊 | 100 | 96 |
| 高斯噪声 | 100 | 45 |
| 中值滤波 | 100 | 100 |
| 椒盐处理 | 100 | 100 |
| 缩放往返 | 100 | 94 |

主设置准确恢复了963/1000张合法图的密钥，随后69张被残差阈值拒绝。噪声组本身100/100可恢复，最终仅45/100，因此增加纠错能力并不对应当前主要损失。强亮度则主要在恢复之前失去可用坐标，需要单独处理信息损失。

恒等消融在这批普通实例负例上也达到0/100，且冻结合法覆盖更高。它在之前完整Reprompt+上的表现较弱。这说明不同来源和负例类型必须共同验收；仅凭一批同提示词不同seed图，无法挑出对完整攻击更好的恢复关系。

## 机制结论

前向关系提供了一种能实际恢复密钥的实例约束，在原开发TR攻击上已有可用结果。跨来源验证揭示了当前瓶颈：单一残差阈值混合了可恢复的随机扰动与结构性内容差异，亮度饱和还会减少可用信息。下一步应研究这两类误差如何直接进入恢复可行条件，并验证它相对完整参考拟合是否带来独立价值。

当前合法编辑类型都在早期开发中出现。类型从阈值校准中排除的结果只说明校准敏感性；真正未见类型、裁剪后重缩放等几何处理、公开辅助信息安全和大样本完整攻击仍需独立验收。[成立条件](../../docs/FORWARD_RECOVERY_CONDITIONS.md)列明了模型、秩、噪声与密钥确认的范围。
