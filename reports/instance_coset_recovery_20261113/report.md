# 实际实例密钥恢复

已经实现从查询图特征恢复128位绑定密钥、认证辅助记录并解封原生水印验证材料的完整原型。249完成2110张图片的新特征提取，以及三组私有投影下14760次真实BCH译码；所有成功返回的密钥和原生材料都逐字节一致，实际恢复判定与对应的精确汉明区域逐条一致。

## 数据与协议

100张原生空间GS最终图按50来源校准、50来源评估拆分，另有10张PGID原生GS图用于完整Imprint转移评估。每张登记8个来自四种官方随机处理的视图；九种正式处理查询使用不同种子，五种确定性处理没有登记。另测100张同提示词不同seed实例与30张既有完整Imprint检查点图。

每个重复含110条发布记录、1230个查询、4种方法。原生空间GS的处理图本轮测试内容恢复和验证材料解封；其全部处理图的水印反演未在本轮执行。PGID-GS查询像素与已完成反演完全一致，联合判定使用这些已验证的原生检测结果。攻击输出来自完整151更新任务，本轮没有生成或修改攻击。

[方法说明](../../docs/INSTANCE_COSET_RECOVERY.md)、[协议](../../protocols/instance_coset_recovery_20261113.json)、[执行协议](../../protocols/instance_coset_recovery_20261113_execution.json)和[完整评分](scores.json)给出实现、来源与权限边界。恢复函数不接收参考特征；精确区域对照在真实解码之后单独计算。

## 最大恢复能力

以下固定BCH半径为127，顺序为三组预先固定的私有投影；合法分母包含50张干净图和450张处理图。

| 方法 | 留出合法恢复 /500 | 不同实例误恢复 /50 | PGID-GS合法恢复 /100 | 最终Imprint接受 /10 |
|---|---|---|---|---|
| 干净图裕量选位＋固定BCH | 422 / 419 / 422 | 0 / 0 / 0 | 86 / 88 / 86 | 0 / 0 / 0 |
| 编辑裕量选位＋固定BCH | 466 / 467 / 466 | 0 / 0 / 0 | 95 / 95 / 95 | 0 / 0 / 0 |
| 编辑裕量＋登记模板恢复 | 466 / 467 / 466 | 0 / 0 / 0 | 95 / 95 / 95 | 0 / 0 / 0 |
| 编辑裕量＋陪集组合恢复 | 466 / 467 / 466 | 0 / 0 / 0 | 95 / 95 / 95 | 0 / 0 / 0 |

所有方法的干净图恢复均为50/50。实例编辑信息改善了可靠位选择；本配置中的模板与陪集没有新增恢复。选位会压低登记视图之间的码字变化，因此许多记录的编辑基为空或接近为空。这一证据用于改进后续的码构造。

## 与SSCD比较

校准目标使用全部合法查询的绝对通过率。95%目标下，SSCD单参考在留出集通过481/500，同提示词实例误匹配5/50；使用相同登记视图的多模板SSCD通过476/500、误匹配0/50，int8存储得到相同计数。本轮四个密钥恢复方法的校准最大能力均未达到95%，故不把它们放在95%工作点宣称优于SSCD。

90%校准目标下，第0组编辑裕量固定BCH的门限为108，留出合法恢复454/500；多模板SSCD为448/500，两者不同实例均0/50。完整结果还给出另两组投影，以及单独标注的“按评估合法通过数匹配”的描述性曲线。后者用于检查工作点公平性，阈值没有独立确认意义。

## 成本与实际能力

第0组平均恢复时间：干净裕量固定8.79ms、编辑裕量固定9.30ms、模板11.01ms、陪集13.18ms；不含图像特征提取。110图的登记特征及查询共2110次提取用时88.0秒。三个重复各自的12个基础码检查覆盖0、1、63、127个码字错误；这些是纠错库单元检查，不是图像攻击。

固定版紧凑辅助字段1216字节，四向量版本1728字节，包含选位掩码、码偏移、确认值和MAC，未计入标识配置及原生材料封装。实际JSON记录中，空间GS原生材料封装后约4.8–5.5KB，PGID-GS约2.3–3.0KB，详情见完整评分。SSCD单模板float32为2048字节，九模板int8为4608字节；比较完整系统存储时两侧都要加相同原生验证材料。

登记接口支持独立随机κ；为使四个方法配对，本评测使用私有HMAC产生相同128位κ。该派生过程不在恢复函数内。记录和原生密钥都保存在服务器private_eval，恢复函数通过真实译码获得κ，再使用提供方秘密解封材料。本结果说明实际恢复链路已工作；内容熵、辅助数据泄露与完整系统误报率另外分析。

本配置的机制结论是：收益来自编辑裕量选位，组合码结构尚未产生额外收益。完整结果保留，后续应让码构造显式区分“同类编辑内的随机变化”和“不同编辑状态之间的结构化变化”，并继续以相同登记信息的多模板SSCD作为强对照。
