# 解码区域投影的机制与可检验结论

## 从码字到解码区域

令消息长度为M=256，重复数为R=64。第j个消息位对应坐标集合G_j。现有全符号嵌入把全部R个坐标写成加密及语义调制后的目标符号t_i。实际上，硬多数译码只要求足够多的坐标符合目标。

在固定幅值a_i=|z_i|下，令F为需要反射的坐标。嵌入问题为：

```
minimize  sum_{i in F} 4 a_i^2
subject to  count{sign(z'_i) = t_i : i in G_j} >= 56, for every j
            z'_i in {z_i, -z_i}
```

对每组，当前不符数量为w_j。反射已符合符号只会增加代价并使约束更差；因此最优解只从不符位置中选择max(w_j−8,0)个。取其中a_i最小的坐标即为精确解，可由交换论证证明。各组不相交，所以逐组最优得到该约束集合的全局最优。

与random56相比，改变符号的数量和每组理想判决余量相同；与saturated相比，幅值完全相同。由此可以区分代价选择、写入强度和幅值来源三个因素，而不添加验证模块。

## 一次性理想密文下的高斯不变性

设S是独立均匀的高斯符号向量，A是独立半正态幅值。Z=S⊙A。H(Z)可以是任意确定的辅助图语义变换；密文C独立均匀。令D为原始符号和C⊕H(Z)的差异。

给定任意Z和独立固定置换，D仍均匀，所以D与Z独立。反射指示F只依赖A和D（随机对照还依赖独立排序）。输出符号S'=S⊙(-1)^F在给定A、D后仍是联合独立均匀向量。由于幅值不变，输出Z'=S'⊙A仍为联合标准高斯。

该论证强调对独立理想密文的平均；不能推出固定密钥条件下的高斯分布、真实攻击安全性、低误报率或任意多次复用nonce时的隐蔽性。实际伪随机密文的结论需要相应密码学归约。实验中的每来源身份使用新的密钥/nonce，配对控制共享身份以控制混杂。

## 为何需要完整模型实验

反射代价是初始潜变量距离，不是语义距离。扩散生成器可能把小潜变量改动放大成内容变化；低幅值符号也可能被反演噪声吞没。因此，本方法有两个相反效应：减少对内容的干预，同时降低载体判决余量并把新证据更多放在弱幅值坐标。

主要机制假设是前者足以改善绑定且不损失实际合法接受。若LPIPS下降但合法接受下降，不能把结果表述为成功防御。若minimal56不能胜过同数量random56，则最小代价选择缺少实际支持。若它只胜过独立幅值full而不能胜过saturated，则改进可能来自复用幅值。

## 预声明的误差分解

保留原始嵌入潜变量后，每个查询的符号残差可以逐位拆成：

```
最终残差 = 有意保留的不符符号 XOR 物理信道翻转 XOR 语义绑定差异
```

按“已反射、保留且符合、保留但不符”三类坐标统计物理错误。另用登记语义码重算BA，仅作为不可部署的oracle诊断。此分解是代数归因，不把相关符号当成独立样本，也不证明独立噪声模型成立。诊断只在本轮全部合法验证完成后执行，不改变冻结的判决、56余量或推进门槛。

## 论文叙事成立的证据要求

可陈述的研究问题是：**语义水印是否过度约束了它本来只需要正确解码的潜变量，从而破坏自身绑定对象？** 方法以同一约束优化回答这个问题。若筛选通过，仍需完整已发表Imprint和Reprompt、独立大样本确认、原生SemBind及其他防御比较、实际FPR校准和生成质量评估，才能形成论文级结论。

最小失真编码已有TIFS2011先例，决策区域恢复已有RAIN相关披露，符号调制与内容绑定也已有SemBind及Sign Clamping先例。不能把这些概念分别列为新模块贡献；可发表性取决于这一具体生成端机制、限定理论及实证收益的整体证据。
