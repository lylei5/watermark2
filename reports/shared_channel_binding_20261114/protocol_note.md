# 内容与反演噪声的共同编辑消去

## 机制与可验证前提

上一轮线性配对校正降低了平均误差，在未登记的亮度和模糊条件下却放大了漂移。另一端，直接把查询投影回参考实例，可以恢复错误实例的密钥。新实验测量一种不同的信息：同一张查询图的内容潜变量与原生反演噪声之间的关系。

记内容潜变量的频谱为A，反演噪声的频谱为B。如果一次合法处理在两路上近似表现为相同传递函数H，那么A'=HA、B'=HB。在非零频率上：

`A' conj(B') / (|A'||B'|) = A conj(B) / (|A||B|)`

`log|A'| − log|B'| = log|A| − log|B|`。

这给出相对相位、相对增益两个候选表示。它们不估计编辑类别，也不将查询向参考特征投影。表示是否有用取决于两件事：真实VAE与扩散反演是否近似满足共同处理，以及消去共同变化后是否仍能区分实例。裁剪、裁切边界、JPEG和神经网络的非线性均会破坏精确模型；九类官方合法处理全部保留在评估中。

频域不变量与相位配准已有研究。Ojansivu与Heikkilä的[IEEE Signal Processing Letters2007工作](https://doi.org/10.1109/LSP.2006.891338)研究对中心对称模糊不变的相位配准；Flusser等的[IJCV2023论文](https://link.springer.com/article/10.1007/s11263-023-01798-7)给出更一般的模糊不变量理论。[MarkNull，USENIX Security2026](https://www.usenix.org/conference/usenixsecurity26/presentation/cao)研究噪声与潜变量的关联，并提出反演再生成误差的检测防御。本轮检验的具体问题是：原生水印查询中的两路共同退化，能否产生更稳健且保持实例区分的实际密钥恢复区域。代数恒等式和频域操作作为已有工具使用。

## 冻结比较

协议在提取新表示前冻结，见[完整参数](../../protocols/shared_channel_binding_20261114.json)。八个表示包括相对相位、相对增益、内容相位、噪声相位、两路普通拼接、打乱配对、SSCD和中心化SSCD。前六种均512维；中心估计的内容输入来自GS来源0–3的36张参考/登记图，没有训练神经网络或按负例调参。

原始`permuted_phase`按10个来源循环打乱噪声，会跨越拟合、校准和评估划分，因此作为全局打乱诊断保存。正式配对消融另行在各划分内部循环打乱，中心与阈值均保持来源隔离；该控制额外执行690次真实恢复。打乱需要另一来源的对应查询，只用于机制检验。相对相位、相对增益、单路、拼接和SSCD候选的拟合输入均严格来自来源0–3。

GS来源4–6用于90%/95%绝对合法图校准，7–9用于开发侧评估；TR/PRC各10个来源作冻结迁移。所有来源均属于已观察的研究开发资产。分别报告四类登记处理和五类未登记处理，阈值保持独立于评估负例。

内容VAE取确定性后验均值；反演噪声使用已核验的490条登记/查询资产，其中GS与TR采用作者DDIM，PRC采用作者DPM精确反演。新增10张同提示词、独立随机seed的普通无水印图，执行10次DDIM和10次DPM反演。它们是实例区分对照，不复用原水印初始噪声，也不改变或新增攻击。攻击仍读取完整151更新的CVPR2025 Imprint既有输出。

SSCD单参考、九模板float32/int8以及每种新表示的连续距离均在同样的像素上比较。九模板SSCD额外保留同源八张登记视图；完整开销单独报告。原始SSCD在490张共同图片上与既有结果进行数值重放核对。源间所有有向干净图配对也加入实例区分测量。

## 完整恢复链

每种表示使用相同的三组私有随机投影、1023位BCH码和128位随机绑定密钥，登记只依据该实例的干净图选择可靠位。连续判定与实际BCH解码分别报告；失败计入合法分母。总计划17040次实际恢复、710个原生记录/查询对。

恢复出的绑定密钥解封一个经过认证的数据密钥；数据密钥再解密该实例完整的原生验证材料，并直接调用原作者检测函数。这种常规信封加密使各方法共享同一份大体积原生材料，内容辅助字段单独计费。记录认证、密钥确认、材料字节一致性与原生检测重放均执行检查。恢复器接收查询表示、经过认证的辅助记录和服务端秘密；参考特征只用于独立的区域诊断。

[预检查](preflight.json)已通过共同滤波的数组恒等式测试、五种已有登记方式的逐字段一致性，以及仅参考图登记后的实际恢复。数值实验、模型与CPU解码全部在249执行；GPU任务只申请空闲GPU7，GPU6排除。[派发记录](launch.json)保存冻结协议哈希，提取结束后顺序执行解码，无进度轮询。
