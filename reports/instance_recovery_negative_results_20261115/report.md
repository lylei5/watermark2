# 实例密钥恢复：结论与负结果

**结论：当前实例密钥恢复实现能够准确返回登记密钥，但没有建立相对直接参考验证的稳定独立收益。该研究线已冻结，保留代码、逐样本数据与失败证据供复核；当前实验优先级为 SemBind、PGID、SEAL 的统一比较。**

| 问题 | 已完成的关键证据 | 能支持的结论 |
|---|---|---|
| 密钥恢复能否工作？ | 部分序实验完成 11,400 次解码，7,552 次成功均返回准确密钥和认证载荷 | 功能正确不等于视觉防伪有效；错误图恢复正确密钥仍是防御失败 |
| 是否超过相同信息的直接验证？ | 已知合法图同为 993/1000 时，部分序恢复与直接部分序参考拟合均接受同提示词其他实例 0/100，九模板 SSCD 为 18/100 | 局部优势来自内容关系，尚无恢复层独立判别收益；这些是评估集上的描述性阈值匹配 |
| 能否处理新的几何编辑？ | 部分序恢复在 WAVES 对比度、旋转、裁剪缩放下分别 500/500、3/500、18/500；九模板 SSCD 三者均 500/500 | 固定空间对应限制泛化；来源图已使用，留出的是编辑类型 |
| 多尺度或可见性恢复能否拒绝重新生成？ | TR 合法 95/100 时，可观察尺度恢复对两代理 Reprompt+ 接受 8/10、7/10 来源；同合法 SSCD 为 1/10、1/10 | 可恢复的局部结构仍可由既有重新生成基线保留；固定交集与可观察规则在 240 张候选上判定相同 |
| 共同频谱能否消除合法编辑？ | TR 共同相位最多恢复 19–21/100，同一码器 SSCD 为 83–84/100；90% 和 95% 校准均不可行 | 图像处理经过 VAE 和反演后，不满足足够稳定的共同响应假设 |
| 成本或隐私是否构成独立价值？ | 部分序辅助 JSON 为 66,184 字节，直接参考 uint8 表示 12,288 字节，九模板 float32 SSCD 18,432 字节 | 未建立存储优势；辅助数据隐私、内容熵、操作系统隔离和整体误报保证均未证明 |

噪声改善需分别归因：旧流程在 100 张噪声图上已恢复 100 把正确密钥，后置残差门槛使最终通过降到 45；不能把 45→95 全部归因于新解码器。相同辅助幅度下，前向恢复为 85/100，部分序恢复为 95/100。删除饱和白坐标的 400 次消融没有改变 200 个配对判定。

对相同输入信息和计算权限，保存完整参考与辅助信息的验证器可以执行同一恢复算法。因此，“恢复了一把密钥”不会自动增加图像判别信息；独立价值必须来自可检验的协议、权限或资源差异。本项目尚未建立这些差异的优势。这是对当前实现和设定的结论，不是否定所有密钥恢复协议。

本页汇总既有冻结实验，未新增模型运行。多个处理共享同一来源，检查点与候选不计为独立样本；当前小型攻击队列不能支持低误报或总体优越性声明。原生联合检测、纯内容判断及仅密钥/载荷返回分别保留。具体来源、分母、统计范围及复现入口见[附录索引](appendix.md)。
