# PGID 官方九条件：新执行结果

10 个固定开发集源图，九种不组合的官方 Gaussian Shading 失真，每个查询分别做标准检测与完整 PGID，共 180 条推理记录。所有潜变量哈希和消息分数已在服务器用官方 GS 解码器独立重算通过。

| 条件 | 标准接受 | PGID 后接受 | 丢失 | 恢复 |
|---|---:|---:|---:|---:|
| random_crop_ratio | 10/10 | 6/10 | 4 | 0 |
| random_drop_ratio | 10/10 | 3/10 | 7 | 0 |
| brightness_factor | 10/10 | 7/10 | 3 | 0 |
| jpeg_ratio | 10/10 | 10/10 | 0 | 0 |
| gaussian_blur_r | 10/10 | 5/10 | 5 | 0 |
| gaussian_std | 10/10 | 7/10 | 3 | 0 |
| median_blur_k | 10/10 | 10/10 | 0 | 0 |
| sp_prob | 10/10 | 7/10 | 3 | 0 |
| resize_ratio | 10/10 | 6/10 | 4 | 0 |

合计标准检测 90/90，PGID 后 61/90，29 个查询失去接受，0 个恢复。此前同批干净图经过 PGID 为 10/10，官方完整 Imprint 151 次更新后为 0/10 接受。合在一起，结果支持研究防御对失真合法图的保真代价，而不是只报告伪造拒绝率。

这不是 90 个独立样本：只有 10 个源图，条件内重复相关。失真强度取自官方脚本，未做人类语义不变性标注。不能把这些结果外推到总体误拒率，或与另一数据集、另一反演器下的 SemBind 直接排名。

同批配对链路的后续证据已完成：[九条件与反演诊断](../sembind_published_revalidation_20261112/report.md)、[完整 Imprint 重验](../imprint_fresh_revalidation_20261112/report.md)。

按源图聚合（见[source_analysis.json](source_analysis.json)），10个源图中9个至少丢失一个条件；两张各仅2/9通过。该分布表明问题不只集中于单张源图，但不改变开发样本量及条件相关性的限制。
