# SemBind 第一阶段：规格与工作点核验

最终论文的 GS-S 参照数值已核对：SD2.1 代理的 Imprint 在 SDP 为 0.04/0.06/0.07、COCO 为 0.09/0.10/0.10；Reprompt 的 SDP 为 0.60/0.56（SD2.1/SD1.5），COCO 为 0.06/0.10。来源为最终版 Tables 2–4、§4.1–4.4，已检查 PDF 第 6–8 页。[出版记录](https://proceedings.mlr.press/v306/zhang26hj.html)，PDF SHA256 见[核验记录](audit.json)。这些是论文参照值，不是本项目实测结果。

## 工作点的确定结果

以下为 249 上的精确二项尾概率计算，不是图像实验：

| 判决 | 最少正确位 | 理想 FPR |
|---|---:|---:|
| 历史 BA > 181/256 | 182 | 5.63480697e-12 |
| 原 GS 源码 BA >= 166/256 | 166 | 1.17609800e-6 |
| 独立公平匹配位模型 BA >= 167/256 | 167 | 6.22289335e-7 |

[GS 原码](https://github.com/bsmhmmlf/Gaussian-Shading/blob/09c678fadc7545acf7be12647ddf2a5e66f6a9dc/watermark.py)用 `P(K>i)` 选 i，判决却使用 `K>=i`，存在一位边界差异。当前不改原码，将原判决和理论对齐判决并列。

64 个独立公平票的平票概率为 **0.09934675**；固定判 0 后，译码位为 1 的概率是 **0.45032662**。新随机均匀消息的平均匹配位仍可为公平位，但固定消息的误报不相同。167 位门槛下，含 112/128/144 个 1 的固定消息理想 FPR 分别为 **1.47901621e-6 / 5.51659714e-7 / 1.98733775e-7**。不能仅凭均匀消息平均值声称每个用户都达到同一 FPR。

0/50 和 0/100 的双侧 95% Clopper–Pearson 上界分别为 **7.1122%**、**3.6217%**。若零事件且真正独立，要使单侧 95% 上界不超过 1e-6，至少需要 **2,995,731** 次试验；复用图片或身份的相关比较不能直接按这个分母计算。

## 仍需闭合的实现规格

| 项目 | 已核对事实与执行要求 |
|---|---|
| GS 重复布局 | 原版 `channel_copy=1, hw_copy=8`，4×8×8 消息按空间块重复；项目旧 full 载体采用扁平 64 次重复。新基线直接调用原 GS 组件。 |
| GS 密钥形式 | 原脚本默认随机位 XOR；可选 ChaCha 分支使用 12 字节 nonce。旧项目使用 cryptography 的 16 字节 nonce 接口。两种原版分支不得混称同一个配置。 |
| 语义绑定 | 论文为 1024 位码、平铺、ratio 选择、秘密置换、符号调制；GS 的 sigma=1。固定当前官方树仍未发布完整绑定/评测入口。 |
| 生成/验证 | 论文 SD2.1、512×512、DPM 50 步、生成 CFG7.5、exact inversion 50 步、inverse order0；解码器优化及具体 CFG、数值兼容层须逐项记录。 |
| 攻击反演 | 论文 §4.1 声称 exact inversion 也用于攻击。项目此前的完整 Imprint 调用为官方 DDIM 路径，不等于该论文攻击端已经对齐。 |
| 更新计数 | 论文为 150 次梯度更新；既有上游脚本的零起始 0…150 是 151 次，保存的 51/101/151 不能冒充 50/100/150。 |
| 数据和质量 | 论文每格 100 prompt，Reprompt 使用 I2P 目标，FID 用 5000 COCO 图、CLIP 用 1000 SDP 图并重复 10 次。较小样本或不同目标数据只作明确标注的核验。 |
| 模型与其他后端 | 本地 SD2.1 为 Manojb 镜像，权重同一性需证据；SD1.5、PRC 和 GS++ 的可用性和完整判定另行核查。 |

官方树为 `337c9f90a150157ac1d410208ae20e6530ca8cdd`，公开清单见[源码树快照](sembind_tree.json)。这项工作完成了规格与理论工作点审计，没有完成新的模型基线或经验 FPR 评估。

当前执行规则见[第一阶段协议](../../docs/PHASE1_PROTOCOL.md)。载体实验暂停是基于已有失败结果的研究决策，不是对所有可能载体的穷尽证明。最优传输水印已有 [Mathon 等，TIP 2014](https://doi.org/10.1109/TIP.2014.2305873)先例；尚未逐式核对时不宣称本项目映射与其完全相同。
