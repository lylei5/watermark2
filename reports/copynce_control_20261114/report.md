# CopyNCE作者公开模型的水印实例对照

本轮将ICCV2025 CopyNCE的两个公开基础模型加入防御比较：512维描述子和读取参考图的配对匹配器。两者沿用作者模型、检查点和预处理，使用与共同频谱恢复相同的图片、记录和校准来源。该结果衡量公开模型在当前水印数据上的迁移。

## 来源与执行

[正式论文](https://openaccess.thecvf.com/content/ICCV2025/html/Lu_Tracing_Copied_Pixels_and_Regularizing_Patch_Affinity_in_Copy_Detection_ICCV_2025_paper.html)通过像素追踪构造局部对应监督，训练描述子和匹配器。[作者代码](https://github.com/eddielyc/CopyNCE/tree/c2223d18abf3289202666a0d2b9db1c3a7f1b483)固定为`c2223d18abf3289202666a0d2b9db1c3a7f1b483`，使用公开的第30轮ViT-S、224×224基础检查点。模型在本批水印数据上未微调；局部裁剪集成、分数归一化和未公开的其他检查点不在本轮范围。

两个模型的推理参数严格匹配作者检查点。描述子额外的训练损失温度字段按作者加载行为排除。依赖timm固定0.9.2；实际PyTorch2.5.1与作者要求2.1的环境差异保留在[预检查](preflight.json)。图像逐张核对RGB像素哈希，预处理为作者的双三次224缩放、张量化和ImageNet标准化。

GPU7提取完成440条载体/查询观测，包含410种RGB像素内容，形成710个发布记录—查询配对。计算用时见[提取记录](extract_complete.json)。模型进程只接收图片与公开任务清单；载体密钥和恢复辅助材料在独立验证阶段使用。这个边界是进程输入隔离，未部署操作系统访问沙箱。

## 冻结校准下的内容判断

阈值仅取GS来源4–6的30张合法图，90%与95%目标分别取第27、29个排序距离。GS评估为来源7–9，TR/PRC各10个来源直接迁移相同阈值。合法图包含干净图和九类处理；未登记处理包含亮度、JPEG、模糊、中值滤波和缩放。

| 校准目标 | 模型 | GS合法 /30 | GS未登记处理 /15 | TR合法 /100 | TR未登记处理 /50 | PRC合法 /100 | PRC未登记处理 /50 |
|---|---|---:|---:|---:|---:|---:|---:|
| 90% | 描述子 | 28 | 14 | 88 | 48 | 91 | 48 |
| 90% | 匹配器 | 28 | 15 | 91 | 48 | 90 | 49 |
| 95% | 描述子 | 30 | 15 | 93 | 49 | 96 | 49 |
| 95% | 匹配器 | 29 | 15 | 98 | 50 | 95 | 50 |

95%校准时，匹配器对GS/TR/PRC的同提示词其他实例、错误发布记录、完整Imprint输出均为0接受。描述子在TR接受6/10同提示词实例、6/90错误记录和2/10完整Imprint；PRC对应5/10、12/90和0/10。GS描述子接受1/3同提示词实例，错误记录与完整Imprint均为0。这些是内容判断，联合水印结果另列。

描述子的90%校准点在三个载体上均拒绝上述三类负例，合法通过数也较低。这说明工作点选择影响明显；不能将一个方法的宽松合法点和另一个方法的严格负例点拼成单一结果。

## 联合原生水印的公平比较

下表使用同一GS95%校准规则。数字为最终联合通过数，合法图分母GS30、TR/PRC各100；完整Imprint分母GS3、TR/PRC各10。

| 方法 | GS合法 | TR合法 | PRC合法 | GS/TR/PRC完整Imprint |
|---|---:|---:|---:|---|
| SSCD单参考 | 29 | 98 | 64 | 0 / 0 / 0 |
| 中心化SSCD | 30 | 98 | 64 | 0 / 0 / 0 |
| SSCD九模板float32 | 29 | 98 | 64 | 0 / 0 / 0 |
| SSCD九模板int8 | 29 | 98 | 64 | 0 / 0 / 0 |
| CopyNCE描述子 | 30 | 93 | 64 | 0 / 2 / 0 |
| CopyNCE匹配器 | 29 | 98 | 59 | 0 / 0 / 0 |

CopyNCE匹配器在TR与SSCD同为98/100，PRC则少5张。按来源进行10000次配对bootstrap，匹配器减SSCD的合法联合通过率差值为：GS0个百分点，95%描述性区间[-10,10]；TR0，[-4,4]；PRC−5，[-9,−1]。这些区间以冻结阈值和当前少量开发来源为条件。

评估集上匹配绝对合法通过数后，TR的95/100点，SSCD系列和CopyNCE匹配器均拒绝全部完整Imprint、错误记录和同提示词其他实例；CopyNCE描述子接受2/10完整Imprint、32/90错误记录，联合接受1/10同提示词实例。PRC匹配64/100合法通过时，六个内容对照均拒绝这三类负例。[比较明细](comparison.json)同时保留其他工作点。

与PGID对照时采用相同TR/PRC图像。作者工作点下PGID合法TR60/100、PRC29/100，完整Imprint均0/10；TR描述性地调到95/100合法通过后，完整Imprint9/10、普通封面4/10。SSCD及CopyNCE匹配器在TR95/100点对应均0/10。PGID使用其原生验证信息，内容参考方法另有每图登记参考；该信息差异和各自成本与防御效果同时呈现。[PGID完整工作点](../recovered_carrier_transfer_20261113/pgid_working_points.json)。

## 编辑类型从校准中留出

每次从GS校准集中删除一类未登记处理，剩余27张图选95%阈值，再只测试删去的处理。五轮合并后，GS15张、TR/PRC各50张；每张合法查询只对应一次留出判断。

| 内容对照 | GS内容；联合 /15 | TR内容；联合 /50 | PRC内容；联合 /50 |
|---|---|---|---|
| SSCD单参考 | 14；14 | 47；47 | 45；38 |
| SSCD九模板int8 | 13；13 | 44；44 | 44；37 |
| CopyNCE描述子 | 15；15 | 49；49 | 49；38 |
| CopyNCE匹配器 | 15；15 | 50；50 | 50；38 |

每个留出阈值下，匹配器的同提示词其他实例、错误记录和完整Imprint内容接受均为0。各轮负例复用同一批图片，不能累加成五倍独立样本。结果支持匹配器在这五类处理上的迁移能力；公开模型预训练使用过哪些增强属于另外的范围。[逐类阈值、可行性及负例](../shared_channel_binding_20261114/heldout_edit_calibration_with_negatives.json)保存全部结果。

## 信息和成本

SSCD、CopyNCE描述子均保存一个512维向量，float32为2048字节；int8九模板SSCD的向量主体为4608字节。CopyNCE匹配器在此次实现中读取完整参考图并执行配对推理，图像尺寸与编码决定实际登记存储。恢复方法还保存辅助记录及原生材料的认证封装。这些字段在各自执行记录中分开核对。

CopyNCE作为成熟内容匹配对照参与比较；本轮未将其描述子或匹配器接入新的密钥恢复算法。内容门控与实际恢复的角色分别保留，以定位表示信息与译码覆盖各自的影响。

全部图片属于开发资产。错误记录的90个配对复用10个来源，三个GS评估来源也较少。相同合法通过数比较是评估集上的描述性工作点；来源bootstrap固定当前阈值，用于展示本批来源的波动。
