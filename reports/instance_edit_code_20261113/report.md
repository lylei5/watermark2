# 编辑状态码的实际恢复实验

249完成三组私有投影、四种方法、14760次真实128位密钥恢复。每个查询执行BCH译码、密钥确认、原生验证材料解封；成功材料逐字节核对，所有判定与相应精确恢复区域一致。

## 方法与数据

本轮把选位标准改为“同类编辑内稳定、不同编辑状态间允许规律变化”：由四类登记视图的组内方差归一化各状态的最小投影裕量。固定BCH、五中心模板与最多16个陪集组合使用相同选位。编辑裕量固定BCH作为复现对照。

沿用[首轮协议](../../protocols/instance_coset_recovery_20261113.json)的2110张图特征、来源拆分、三组投影与配对密钥。本轮新执行登记和解码，没有重新提取图片特征。来源哈希见[特征记录](features_complete.json)，代码与参数见[本轮协议](../../protocols/instance_edit_code_20261113.json)、[执行协议](../../protocols/instance_edit_code_20261113_execution.json)。这是已观察开发数据上的方法迭代。

模板弥补了部分跨状态变化；陪集组合没有增加成功样本。完整结果保存在[scores.json](scores.json)，包括共同90%/95%校准目标、单独标注的评估匹配曲线、分条件结果和成本。多模板SSCD的95%校准工作点仍为476/500、不同实例0/50；本轮实际恢复方法都未达到95%校准目标。

## 恢复出的材料已进入原生检测

[原生验证记录](native_key_verification.json)使用第0组投影，对100张空间GS干净图和130张PGID-GS查询重新执行920次密钥恢复。恢复出的材料直接构造原作者GS检测器，复用经过哈希核验的既有反演潜变量。195次不同的原生检测调用全部重放相同BA；多个方法恢复相同材料时复用这次新检测结果。

编辑裕量固定BCH的空间GS干净图为100/100，PGID-GS合法查询为95/100，完整Imprint最终输出为0/10。模板和陪集的PGID-GS合法查询均91/100。全部恢复失败保留在分母中。

另用登记接口默认的独立随机密钥完成一次恢复，并通过修改记录ID、错误提供方秘密的两项认证检查。第一次验证启动缺少Crypto依赖；安装pycryptodome4.4.0后完整执行，初次失败日志保存在服务器，未产生评分。此处增加的是原生比特检测；扩散反演沿用既有缓存。

## 机制结论

离散模板能处理已登记的跨状态翻转，二元线性组合在本组实验中没有额外作用。后续的[连续编辑方向恢复实验](../instance_edit_quotient_20261113/report.md)在量化前处理漂移，继续保留固定BCH和多模板SSCD的配对比较。
