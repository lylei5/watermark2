# 最终发布实例的内容绑定

研究目标：让水印认证回答“这张图是否仍对应这次发布”，同时保留压缩、缩放等处理后的合法图。原生 GS/PRC 负责承载水印；实例身份的稳定性与区分性单独验证。

## 当前机制问题

已有100提示词结果揭示了两种误差：辅助图到最终图会变；同提示词的不同实例又被 SemBind 码器主动拉近。扩大一个统一汉明球会同时容纳这两类变化。纠错能够恢复受扰码字，表征空间中已经重叠的两类图仍需先分开。

这一轮固定三个表征对照：作者 SemBind 1024位码、同一 DINOv2-giant 主干的归一化 CLS 特征、作者 SSCD disc_mixup 描述子。分别从辅助图和最终发布图建立参考，测量相同的九种 GS 官方图像处理和同提示词独立 seed 实例。这样能定位信息在主干、哈希头和参考图选择中的损失。

[实验协议](../protocols/instance_representation_20261113_v2.json)按提示词族分开50个校准来源和50个评估来源；所有图片来自已观察的开发数据。每种表征与参考方式独立选取覆盖至少95%校准失真的最小距离阈值，再固定到评估侧。干净图与每个失真条件分别报告，保留全部来源。

## 方法选择标准

第一步建立 `原生载体检测 AND 最终图实例距离门限`。它是必须超过的简单防御对照。额外的模糊提取器若产生相同接受集合，只能带来协议或存储方面的变化；防伪收益需要另有证据。

第二步研究**实例恢复区域**：同一图的处理误差应留在区域内，同提示词其他实例应在区域外。先测连续特征的可分性，再决定是否需要二值化训练和纠错。若连续特征已可分而二值码不可分，重点放在保留实例间隔的码器；若连续特征也重叠，先查哪些处理抹掉了可辨认信息。

候选机制须通过四项检验：

1. **身份自洽。** 生成结束后登记最终图，或证明生成前的内容参考经过嵌入后仍是同一实例；统计所有失败和额外生成成本。
2. **恢复区域分离。** 在固定合法保留率下分开同图编辑和其他实例，报告每种失真及来源层面的区间。
3. **完整防御收益。** 在同载体、同反演、同数据下，对原发表完整 Imprint/Reprompt 作配对比较；不靠拒绝更多合法图取得优势。
4. **协议独立价值。** 相对于简单距离门控，明确减少的存储、密钥暴露、查询成本或误匹配；给出支持该差异的证明或实验。

当前已完成实际128位密钥恢复与原生检测，使用冻结SSCD及实例登记编辑构造恢复区域。新的码器训练尚未执行；论文贡献围绕区域分离、协议性质和共同工作点收益建立。

## 已完成的机制测量

[表征实验](../reports/instance_representation_20261113/report.md)中，最终图参考下SSCD保留428/450处理图、误匹配1/50不同实例；SemBind码为420/450、42/50。相同SSCD改用辅助图参考后，误匹配49/50。该对照将辅助图身份错位与表征粒度两个因素分开。

[二值化实验](../reports/sscd_binary_fe_20261113/report.md)进一步发现，固定随机投影的1024位恢复半径达到385–390；登记时选择远离投影判定边界的位，可将其降到214–220，评估误匹配三次均为1/50，处理图保留426–434/450。这是沿现成可靠位选择思路得到的对照证据。对应普通BCH设计的码维数仍只有36–46，后续应研究实际恢复码率、辅助数据和公开选位后的条件信息，而非直接部署128位内容密钥。

现在的候选主线是**最终实例的可恢复绑定**：先固定发布实例，再让同图处理落入可恢复的内容区域；载体保持原生。可主张的创新需要体现为区域构造或完整协议的新增性质，并超过SSCD直接距离门控。完整Imprint对照已按退出事件衔接到TR/PRC原生任务，固定使用本次校准阈值。

## 密钥恢复与距离门控的关系

下面是本项目的协议推导，用来确定模糊提取器的实验价值。

设一条经过认证的发布记录保存实例码w、恢复辅助数据P和载体密钥封装。验证器先计算查询码w'，限定在d(w,w')≤t时恢复该记录的唯一密钥K，再调用完全相同的原生水印检测器B(K,x)。若恢复在球内完整正确，球外拒绝，且密钥确认只接受该记录的K，则完整接受事件为：

`Accept_FE(x, record) = [d(w,w') ≤ t] AND B(K,x)`。

在这些明确条件下，直接距离门控具有相同的接受集合。辅助数据与密钥封装可以改变存储和访问方式，防伪率由同一个内容区域和载体判定决定。若实际恢复器只能覆盖区域的一部分，应额外计入这些合法恢复失败。一般模糊提取器仅保证规定距离内正确，严格球外拒绝需要另行实现。[标准定义](https://www.cs.bu.edu/~reyzin/papers/fuzzy.pdf)

同样，对于任意分布，`P(content AND carrier) ≤ min(P(content), P(carrier))`；将两项概率相乘需要额外的独立性条件。伪造输出中的内容和载体来源相关，实验应保存两项连续分数和联合判定。

这一推导把研究重点落在**恢复区域的形状与实例信息**。先得到比统一汉明球更好的合法编辑覆盖与实例分离，再选择匹配该区域的码和恢复协议。当前的三表征、双参考实验用于判断这个前提。

## 载体误差能否帮助内容恢复

待验证的机制是：一次合法处理同时作用于图像内容和水印载体。若载体读出中的错误能预测实例特征的变化，内容恢复区域就可以随可观测的处理误差变化。需要先测清这种依赖，再设计恢复算法。

[冻结诊断协议](../protocols/carrier_content_channel_20261113.json)重新运行10个PGID原生GS来源的130次检测：10张干净图、90张官方GS处理图、30张既有完整Imprint检查点输出。原生载体采用其作者的256位、64重复实现，DDIM50。攻击图片来自已完成的151更新任务；本轮只重新提取SSCD、反演图片和读取载体，没有生成攻击。

主变量是多数投票前16384个载体坐标的错误率，以及查询图到最终发布图的SSCD距离。先用来源0–3的36张合法处理图拟合非负斜率，再由来源4–6的27张合法处理图校准95%覆盖阈值，固定到来源7–9。干净图、全部处理图和三个攻击检查点分别报告。载体判断保持`BA > 181/256`；直接SSCD门限同时报告旧固定阈值和同校准集阈值。按来源留一的预测误差、去除处理类别均值后的相关性用于判断关系是否能跨图片成立。

这项诊断对应持有原生载体身份的验证器。载体误差依赖该身份的密钥，因此不能同时把该密钥设为读取误差之后才解出的唯一秘密。后续协议须明确身份查找密钥和待恢复的实例认证凭据各自的作用。

### 创新落点与已有方法的界限

内容特征、纠错和签名组合已有长期研究，例如[Sun与Chang的ICIP2002工作](https://www.ee.columbia.edu/~qibin/papers/qibin2002_icip_1.pdf)。[Two-Phase Method for Image Authentication and Enhanced Decoding，IEEE Access2017](https://ieeexplore.ieee.org/document/7959560/)还利用信道侧信息做认证，并将认证过的数据反馈给译码器。因此，加入纠错或利用信道信息本身都不足以构成贡献。

[Latents-Inv，IJCAI2026](https://ijcai.org/proceedings/2026/75)通过可逆网络把水印信息分配到潜变量与所有者保存的辅助密钥，并训练负配对抑制误认；它改变嵌入编码。本项目讨论的载体保持原生，待恢复对象是最终发布实例。两者的区别需要在实际存储、查询成本和同工作点收益上体现。

有价值的进一步问题是**同一次处理的一致性**：内容变化和载体变化是否能由同一个处理过程解释。两个各自放宽的门限允许分别解释两项变化；联合恢复区域则应保留它们之间的对应关系。标量线性校准只是检查这一前提的简单对照。若它能预测内容漂移，下一步研究条件恢复区域；若预测关系弱，就停止将标量载体误差作为恢复依据。

完整方法需要同时给出三个结果：联合区域相对SSCD门限和通用分数融合的收益；区域内实际恢复的成功率与辅助数据开销；相同合法检出率下的完整已发表攻击结果。上述机制和收益目前处于实验验证阶段。

[普通子空间对照](../reports/instance_nuisance_geometry_20261113/report.md)已经完成：移除16个全局处理误差方向后，连续门控430/450、不同实例误匹配0/50；1024位码的三次恢复半径仍为193、187、207。64个方向在拟合来源上解释80.32%的误差，在留出来源上解释23.22%。全局校正提供了更强的对照，也提示需要研究实例自身的处理误差，而非统一扩大恢复半径。

### 配对诊断的结论

[130张图的配对测量](../reports/carrier_content_channel_20261113/report.md)已完成，全部原生BA重放一致。条件门限在预先留出的27张处理图中保留27张，直接校准SSCD保留26张；全部90张处理图上分别为85、87张。两者均拒绝10个来源的完整Imprint输出。

载体坐标错误率的按来源留一预测R²为0.4263，潜变量RMS为0.4981；空间分块后，同样16维的错误率为0.5954，RMS为0.6863。同样32维下，潜变量均值与RMS为0.7937，载体错误率与RMS为0.7507。通用反演统计是当前更强的信息来源对照。后续恢复区域需与条件门限、普通全局校正一起比较。

当前主线为**最终实例的可恢复绑定**。三轮[实际恢复实验](../reports/instance_edit_quotient_20261113/report.md)已完成：可靠选位、编辑状态码和连续实例编辑方向均接入真实BCH译码、128位密钥确认、原生材料解封。恢复函数不接收参考图特征；原生GS检测已直接消费恢复材料。

八方向版本在共同90%校准目标下的合法恢复为455/460/457，多模板SSCD为448，分母均500；不同实例均0/50。最大恢复能力为473–477/500；95%校准能力尚未达到目标。辅助字段9408字节，大于int8九模板的4608字节。按来源的bootstrap区间跨投影仍有波动。切空间投影具有既有方法基础，当前贡献候选应继续用完整迁移与独立数据检验，不能只以增加BCH或更换名字建立创新。

[TR/PRC迁移协议](../protocols/recovered_carrier_transfer_20261113.json)已冻结并排队：相同登记图片、冻结GS阈值、280次原生反演、3360次真实恢复，和原生PGID及多模板SSCD配对比较。所有攻击图来自已有完整预算Imprint进程，新的工作只执行防御与验证。
