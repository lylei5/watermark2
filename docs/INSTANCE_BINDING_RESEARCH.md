# 发布实例的可恢复内容绑定

研究目标是让水印认证对应具体的一次图像发布：合法压缩、缩放等处理后仍能恢复该实例的验证材料，同提示词其他图片和已有伪造输出被拒绝。原生GS/TR/PRC载体保持各自定义。完整实验、失败和冻结协议保存在[报告索引](../reports/README.md)，当前执行状态只由[project_state.json](../project_state.json)维护。

## 已经成立的实现与观察

实际恢复链路已运行：登记最终图，构造实例区域，BCH恢复128位密钥，认证解封原生材料，并由作者检测函数验证查询图。成功密钥与材料逐字节核对。实现采用服务端秘密，属于计算型密钥绑定；内容熵和经验误接受率仍需单独测量。

- [表征对照](../reports/instance_representation_20261113/report.md)：最终图参考下，SSCD处理图428/450、不同实例误匹配1/50；SemBind语义码对应420/450、42/50。辅助图身份漂移与提示词级不变性是两个不同问题。
- [实例方向恢复](../reports/instance_edit_quotient_20261113/report.md)：八方向版本的最大恢复为473–477/500，共同90%校准点为455/460/457；int8九模板SSCD为448/500。95%校准恢复目标尚未达到，辅助记录9408字节。切空间校正和可靠位选择已有方法基础。
- [TR/PRC迁移及PGID合法对照](../reports/recovered_carrier_transfer_20261113/report.md)：280次原生反演、3360次实际恢复，2179次成功全部准确。PGID合法通过为TR60/100、PRC29/100，原生为100/100、64/100。八方向的TR联合通过91/90/89，多模板int8为90，单参考SSCD为95；这是该轮冻结GS90%工作点。来源重采样的三组区间均跨0。
- [配对编辑恢复](../reports/paired_channel_recovery_20261113/report.md)：编辑侧信息降低平均残差，却损伤未登记亮度和模糊的恢复。95%校准点为45/46/45，九模板SSCD为48，分母50。内容自拟合会把实例差异一起消掉。
- [共同频谱机制](../reports/shared_channel_binding_20261114/report.md)：用内容潜变量和原生反演噪声的相对相位、对数增益差尝试消去共同编辑。完整频谱能区分普通错误记录，但TR仍接受9/10完整Imprint。17730次真实恢复判定已完成；共同相位TR最大密钥恢复19–21/100，SSCD同码器83–84/100。配对消融、原生调用和编辑类型留出分析分别保存。
- [CopyNCE强对照](../reports/copynce_control_20261114/report.md)：作者公开描述子与匹配器在同像素、同校准来源上执行。冻结GS95%点，匹配器TR内容判断为98/100合法、0/10同提示词其他实例、0/90错误记录、0/10完整Imprint。联合原生检测后，匹配器TR98/100、PRC59/100，SSCD为98/100、64/100。匹配器读取完整参考图，成本与512维描述子单列。

PGID的抑制效果伴随合法通过率下降。在TR评估数据上描述性地将其调到95/100合法通过时，完整Imprint接受9/10；相同合法通过数的SSCD为0/10。该阈值比较用于解释权衡，作者原工作点与其FPR含义仍单独保留。PRC当前原生合法检测64/100构成任何纯内容门控的联合通过上限。

## 密钥恢复应增加什么价值

设经过认证的发布记录对应内容码w、辅助数据P和原生载体密钥K。若恢复器在d(w,w')≤t内完整正确、球外拒绝，而且密钥确认只接受本记录的K，则最终接受事件为：

`Accept(x, record) = [d(w,w') ≤ t] AND NativeDetect(K, x)`。

因此，在这些条件下，距离门控和恢复协议具有相同接受集合。若实际译码只覆盖区域的一部分，还要计入这些合法恢复失败。一般模糊提取器只保证规定距离内正确，球外拒绝需要额外约束，见[标准定义](https://www.cs.bu.edu/~reyzin/papers/fuzzy.pdf)。

防伪收益由可恢复区域的实例分离决定；密钥封装则可能改变存储、密钥访问和验证方式。这些价值应分别证明。对任意分布，`P(content AND carrier) ≤ min(P(content), P(carrier))`；乘积公式需要独立性依据。原生载体、图像内容与伪造生成过程存在依赖，联合判定必须实际记录。

## 目前的机制判断

未知处理要求保留同图变化；实例区分要求保留图与图之间的差异。扩大统一半径、用查询自拟合参考、移除过多方向，都可能同时消去这两种差异。共同频谱试图利用额外的反演观测解决这个冲突，实测暴露出普通实例区分和Imprint区分的差别。

成熟局部匹配提供了更强的实例证据，但局部特征、几何匹配、模糊金库和编辑估计结合译码都有直接先例。下一项值得检验的问题是：**在限定登记信息和查询成本下，能否保留强配对匹配器的实例间隔，并直接恢复密钥。** 当前尚无通过完整对照的新机制；不将现成局部匹配接纠错作为论文贡献。

下一机制需要事先说明：

1. 查询中的什么观测能识别合法编辑，同时保留实例差异；它比现成描述子或配对匹配多了什么信息。
2. 辅助记录如何定义可恢复集合，恢复函数实际读取哪些私有和公开输入；成功恢复必须对应唯一的发布实例材料。
3. 相同合法通过数下，实例误接受和原样完整预算攻击接受是否降低；或者在相同接受集合下，登记存储、查询或密钥访问成本是否明确降低。
4. 编辑类型从实例登记与本轮阈值校准中同时留出后，收益是否仍成立；公开编码器预训练用过的增强另作说明。

## 后续实验的验收标准

新来源按实例拆分开发、校准和确认，冻结方法后再读取确认结果。全部合法参考进入分母。先比较连续区域和强门控，再实际恢复密钥与原生材料；逐条件列出内容通过、密钥恢复、原生通过和联合通过。只有同时满足机制可解释、同工作点收益或明确协议收益、实际恢复正确性、成本可核对，才将候选升级为论文主线。
