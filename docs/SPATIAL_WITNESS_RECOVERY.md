# 空间证据驱动的密钥恢复

研究目标是让可观察到的实例证据决定密钥能否恢复。未知编辑可能让局部证据移动或消失；另一张同提示词图像则改变了证据本身。原型把这两种变化分别交给坐标估计和错误／擦除译码处理。

两项原型已在249完成。[空间配准恢复](../reports/spatial_witness_recovery_20261114/report.md)执行2310次真实恢复，区域隔离TR合法68/100，拒绝本次Reprompt；[可见性恢复](../reports/visible_witness_recovery_20261114/report.md)执行1540次，TR合法恢复99/100，但Reprompt接受8/10、9/10。同合法通过数下，SSCD仍覆盖这两项原型的防伪收益。以下定义对应这些已完成实验，进一步研究问题见[实例绑定说明](INSTANCE_BINDING_RESEARCH.md)。

注册时，从最终发布图像的右侧区域抽取255组局部亮度次序，每组8位。位置和选位只依赖参考图与注册随机数。随机128位实例密钥用RS(255,16)编码，随后与这些符号做码偏移。helper经过提供方MAC认证，恢复的密钥用于解封载体验证材料。载体生成器保持原样。

查询时，SIFT对应点和RANSAC单应矩阵把查询图映射回参考坐标。主原型仅允许参考图左侧的关键点参与配准，右侧提供恢复证据。右侧亮度次序不会参与估计配准变换。一个符号的采样位置全部可见时，译码器读取其8位；落出画面的符号记为擦除。RS实际译码后检查密钥承诺，并重编码确认 `2e+s ≤ 239`。随后解封原生验证材料，执行GS/TR/PRC原生检测。

冻结的三个版本共享同一helper、同一密钥和同一码：固定坐标、全图配准、参考侧区域隔离的配准。比较回答两个问题：坐标恢复有多少贡献；限制用于估计变换的区域是否保留了更多实例区分能力。全部版本都实际恢复密钥，记录恢复失败原因及原生检测结果。

这里的隔离范围是参考侧：SIFT查询描述子仍来自完整查询图。描述子支持范围采用保守的尺寸规则，尚无严格的统计独立性证明。RS的唯一译码界是代数性质；视觉特征有相关性，不能据此给出图像误接受率或128位视觉安全强度。原型保留全部helper与原生状态的存储成本。

最接近的已有工作决定了创新性检验的重点：

| 已有工作 | 已覆盖的机制 | 本项目仍需证明的部分 |
|---|---|---|
| Lin、Varodayan、Girod，TIP2012 | 编辑参数估计与分布式信源译码联合完成图像认证 | 区域隔离是否形成更有效的恢复区域，而非另一种几何纠错实现 |
| 几何模糊保险箱与局部生物特征密钥绑定 | 局部匹配、缺失容忍、RS恢复随机密钥 | 自然图像中的实例混淆、参考信息成本与对未知编辑的收益 |
| Weng等，ICME2012 | 分块内容哈希、水印认证与篡改定位 | 恢复密钥所需的证据约束是否有独立贡献 |
| CopyNCE，ICCV2025 | 实例复制检测、局部匹配 | 相同合法图检出率下的接受率，以及实际密钥恢复、时间和存储成本 |
| Lin、Shahabi、Song，2026预印本 | 属性保持哈希与可恢复签名；讨论图像嵌入碰撞问题 | 实用图像相似性关系及其可验证性质；本文未实现其密码学构造 |

本原型是机制检验，不把SIFT、RS或区域拆分本身列为新贡献。推进主线的条件是：在固定合法图校准或严格匹配的绝对检出率下，显示区域隔离的独立收益；随后以未使用的新来源确认，并给出已有几何认证方案所不具备的协议性质。若全图配准或强匹配器已经覆盖该收益，就保留为对照。

参考：[TIP2012作者全文](https://web.stanford.edu/~bgirod/pdfs/LinTransIP2012.pdf)、[ICME2012作者机构记录](https://researchportal.vub.be/en/publications/robust-image-content-authentication-with-tamper-location/)、[可恢复签名及图像适用边界](https://arxiv.org/html/2602.15323#S2.SS3)。

## 可见证据与矛盾证据

已有合法图队列中的`random_crop_ratio`把窗口外像素置黑，`random_drop_ratio`把窗口内像素置黑；两者都保留512×512坐标。`resize_ratio`先缩小再恢复原尺寸。该队列可以检验信息缺失和重采样，不能单独证明对裁剪后重排坐标的恢复能力。CVPR2025原作者还提供`crop_scale_TR`，对应真正的随机裁剪并缩放；它尚未进入本轮已完成队列。

第二个原型把255组证据放到17×15带随机抖动的全图网格。相同helper分别用固定坐标普通译码和可见性译码处理。后者把查询采样范围内灰度跨度低于2的符号记为缺失，并要求至少64个可见符号；整个规则在运行前固定，未使用目标提示词、攻击标签或密钥译码反馈。它处理置黑与饱和造成的平坦区域，显式保留有细节却与参考不符的错误。

设可见符号数为`m`、错误数为`e`。RS的条件`2e+(255-m)≤239`等价于`e≤(m-16)/2`。因此成功恢复经过确认的正确密钥时，至少有`ceil((m+16)/2)`个可见符号与注册实例一致；`m≥64`时至少40个。恢复记录可以逐样本核验这一代数关系。这是对所采样局部次序的证据要求，不能直接解释为40个独立视觉区域、整图语义一致或误接受率保证。

该实验单独检验“缺失信息”和“可见矛盾”分开计数的收益。错误／擦除译码本身是已有技术；论文贡献仍需由新的实例证据关系、明确的适用编辑范围和相同合法检出率下的收益共同支撑。

完成后的361条可见性成功返回都满足上述代数条件。合法恢复改善集中于置黑缺失；Reprompt仍可满足粗次序的一致条件。后续证据表达需要约束可见内容的实例变化。变量特征集合改变纠错阈值的效应已有[生物特征模糊保险箱研究](https://arxiv.org/abs/2506.22347)讨论，当前规则的可见性适配不单独列为新贡献。
