# 防御机制：以新执行证据决定下一步

## 当前可采信的观察

[PGID 九条件新实验](../reports/pgid_published_revalidation_20261112/report.md)中，同一90个合法图查询标准检测全部接受，完整PGID后接受61个。按源图聚合，10个源图中9个至少丢失一个条件；两张源图各只保留2/9。因此结果不是单张异常源图造成，但仍只有10个开发源图，不能按90个独立样本估计总体风险。

[新生成的SemBind/GS链路](../reports/sembind_chain_revalidation_20261111/report.md)中18条干净图记录全部BA=1。完整解码器优化降低了信道符号错误率；SemBind辅助图与最终图语义码最低一致率约81.15%，仍通过消息检测。这提示必须同时观察消息恢复与内容绑定，不能把语义码差异直接等同于认证失败。

## 文献约束

| 直接核查的原始来源 | 已有机制 | 对本项目的约束 |
|---|---|---|
| [SemBind §3.2–3.3](https://arxiv.org/html/2601.20310v1) | 语义码扩展、置换后调制潜变量；查询端重建语义掩码 | 使用语义哈希或调整绑定顺序，本身不构成新贡献 |
| [CoverLock §4](https://arxiv.org/html/2609.32241v1) | 内容条件二进制码在消息层进行XOR包装和解包 | 消息级绑定已存在，不能以“绑定放在纠错之前/之后”单独声称首创 |
| [PAI §5.2](https://arxiv.org/html/2601.06639v1) | 将初始化偏差投影到PCA空间，再以Mahalanobis距离检测；所有权与攻击检测使用不同良性分布 | 由单分数改为多维统计、或加入异常分数，单独不够新颖 |
| [PGID v5 §5.3、§6](https://arxiv.org/html/2605.09319v5) | 检查真实水印保留与伪造分离，并明确跨方案/模型可能需要调参 | 本项目九条件属于额外开发集评估，不能包装成原文完全相同设置的反证 |

上表是原文机制核查，不是全领域穷尽查新。实验比较仍须匹配输入、模型、完整预算及检测阈值。

## 要检验的核心问题

问题是：能否在保留合法图像认证证据的同时，区分反演引入的误差与内容绑定不一致，而无需通过改变查询图像来消除二者？这只是研究问题，尚无优越性结论。

对二进制载体，已知身份密文记为c，登记语义掩码为h，查询掩码为q，反演符号误差为e。去掉身份和查询掩码后，残差可写成

`r = h XOR q XOR e`。

这个恒等式本身不能识别两种误差的来源：任意残差都可有多种分解。若提出重复结构的概率模型，必须核查重复间相关性、条件依赖以及可辨识性；不能将反演产生的相关错误当作独立噪声，也不能把同一图像的多个反演视为独立证据。既有项目的混合分布评分不能仅凭公式或历史结果升级为有效新方法。

## 已冻结的判别实验

[执行计划](../reports/sembind_published_revalidation_20261112/plan.md)包含同批SemBind/GS配对、九种既定失真、两种反演设置；每条记录保留查询码、潜变量和图像哈希。

- 查询码拒绝、登记码通过：提示绑定相关的额外损失；登记码仅为诊断信息，不能用于构造不公平的检测器。
- 查询码与登记码均拒绝：优先检查潜变量恢复和信道错误；不能断言语义码完全无贡献。
- 完整解码器优化恢复接受：量化它的实际作用和计算成本，不能将更多算力当作方法优势。
- 两种码均通过：该条件没有提供认证失败的证据。

上述分类自动统计全部条件，不选择最有利样本。随后用完整151次更新的既有CVPR2025 Imprint基线补齐伪造侧证据。保持原攻击更新、所有检查点和原始阈值；不研究或改进攻击。

## 方法进入验证的门槛

只有在新执行结果显示可重复的、可观察的误差结构后，才冻结具体防御规则。该规则需要说明检测时真正可用的信息、与SemBind/CoverLock/PAI的实质差异，以及为何不会将清晰的身份不一致解释为可纠正噪声。开发集选定后在新源图上做确认，比较匹配真实图接受率下的伪造接受率，并报告质量与计算成本。当前没有证据支持宣称优于SemBind。

## 已完成结果与下一项可证伪假设

新执行完整Imprint中SemBind适配器已拒绝全部四个最终候选。条件内容似然未增加伪造拒绝并降低真实接受，不能以信道预测精度提升替代认证收益。共享锚虽改善语义绑定与配对保真，却未通过原始真实保留门槛。详见[完整候选结果](../reports/conditional_anchor_pilot_20261112/report.md)。

下一项[内容耦合分位协议](../reports/conditional_quantile_pilot_20261112/plan.md)把共享内容自由度与载荷位分开，在16384个坐标中保留完整64次身份重复。关键检验为相同编码预算下，来自预览的自由度能否相对独立采样改善绑定，并保留真实接受。分位调制本身已有GS先例；本项目不能据此预先声称创新或SOTA。
