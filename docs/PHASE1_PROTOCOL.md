# 第一阶段：SemBind 基线与轨迹语义核验

目标是完成可审查的论文规格复现、检测工作点核验，以及决定轨迹语义方向是否值得研究。第一阶段不开发载体或攻击变体。已发表攻击保持原实现、参数和完整预算；第三方源码不作修改。

## 基线与工作点

以 [SemBind ICML 2026 最终论文](https://proceedings.mlr.press/v306/zhang26hj.html)为依据。GS-S 优先，GS 配对控制必做；PRC-S 在依赖和检测契约完整后执行，GS++-S 须有可信完整实现。SD2.1 生成，SD2.1/SD1.5 代理分列，SDP/COCO 分列。Imprint 的论文预算是 150 次实际梯度更新，读取 50/100/150；已有 151 次运行的 51/101/151 检查点不能混称相同预算。Reprompt 论文使用 I2P 目标提示词，换成其他目标数据时须单列协议差异。

“复现”需要实现规格逐项闭合和独立数值相容；论文值落入宽置信区间本身不证明等价。首轮每个数据集至少 50 个独立 prompt，正式复现结论按论文的 100 个 prompt；不把同图多检查点计为独立样本。比例报告 Wilson 或 Clopper–Pearson 95% 区间，配对/曲线统计按 prompt 聚类。不得通过看结果后调实现或阈值使其接近论文表格。

工作点并列保存：历史 `BA > 181/256`；原 GS 源码的 `BA >= 166/256`；256 个独立公平匹配位假设下不超过 1e-6 的 `BA >= 167/256`。后者不是实测 FPR 保证。64 票平票按原版判 0，分别测量随机身份平均误报和固定消息条件偏置，不悄悄修改原译码器。

经验 null 区分随机错误身份、固定身份的未加水印图，以及模型生成的未加水印图；报告实际独立单位、样本量和置信上界。零次误报不写成 FPR=0。50 或 100 张自然图不足以验证百万分之一的尾部概率。

## 轨迹语义测量

仅观察正常生成轨迹，不实施中途绑定。记录 50 步 DPM 采样中第 5 至 50 次网络评估对应的 x0 预测，使用相同 VAE 解码及发布的语义网络；与该轨迹最终图计算 `1-Hamming/1024`。报告逐步均值、P5、最小值和按 prompt 聚类的不确定性。

必须有三类控制：SemBind 辅助图与最终图；同 prompt 独立 seed、不同 prompt 的最终图；既定 JPEG 条件。正常轨迹的稳定性只是必要条件，不能证明加入绑定后的轨迹仍稳定，亦不证明实例级防伪或新颖性。

主时间点预先固定为第 35/50 步；如另外探索最早满足条件的时间点，必须用来源分离的数据验证。继续条件包括 P5>0.95，且轨迹内一致性相对辅助图和同 prompt 不同实例有明确的配对优势。不同实例本身高度相似时，不将其称为实例级绑定成功。不通过时先完成机制归因，再决定是否研究 DPM 下的几何语义方向；旧 DDIM 结果不能作为新方法成绩。

## 交付与执行

交付包含基线对照表、工作点和平票结论、弱点排序、轨迹曲线与控制表，以及未闭合的规格/资产清单。没有完成的单元格写明未测及原因。FID/CLIP 标明模型、参考集和样本数；小样本 FID 不与论文 5000 图结果排名。

每完成一个可核验单元，同时提交其代码、协议、报告和项目状态并推送 main。所有模型和 CPU 评分在 249 执行，仅使用空闲 GPU 7、5、4，最多三张，排除 GPU6。等待进程退出事件期间开展独立研究，不持续轮询。
