# 内容密钥与实例绑定的可行性评估

日期：2026-11-13（北京时间）。结论：内容不匹配时停止载体认证是值得验证的防御机制；当前还不能将“模糊提取器＋现有语义码”视为可行方法或已对齐1e-6的工作点。优先解决绑定对象与生成时序，再判断密钥恢复是否比直接内容匹配提供额外价值。

后续已在249完成[最终实例表征比较](../reports/instance_representation_20261113/report.md)和[二值码恢复预算诊断](../reports/sscd_binary_fe_20261113/report.md)。SSCD绑定最终图时明显改善同提示词实例区分，登记时可靠位选择显著降低二值恢复半径；实际模糊提取器和新码器训练仍待推进。机制、相关工作和完整判定的比较要求见[实例绑定研究](INSTANCE_BINDING_RESEARCH.md)。

## 直接证据

100提示词实验中，COCO与SDP各50例。辅助图到GS-S最终图的码一致率均值分别为0.954141、0.894902，最低分别为0.796875、0.700195。该生成链路使用原GS载体与语义符号调制，并非尚未实现的内容派生密钥方案。

从已观察数据选择能覆盖至少95%辅助图→最终图配对的最小汉明半径，得到：

| 数据集 | 半径/1024 | 辅助图→最终图在半径内 | 同提示词不同seed也在半径内 |
|---|---:|---:|---:|
| COCO | 123 | 48/50（96%） | 41/50（82%） |
| SDP | 228 | 48/50（96%） | 45/50（90%） |
| 合并 | 179 | 95/100（95%） | 88/100（88%） |

这是同一数据上的描述性分布重叠，不是独立验证、密钥误恢复率、自然图FPR或攻击成功率。它提示现有码器的辅助图稳定性与实例区分存在冲突；更强纠错不能凭空拉开这两个分布。原始记录、固定半径区间及脚本见[半径诊断](../reports/phase1_hamming_radius_20261113/report.md)。

第35步轨迹一致率P5在COCO/SDP上分别为0.904639/0.892383，均未超过事先规定的0.95。不能把轨迹码视为已经解决生成时序问题的组件，见[轨迹测量](../reports/phase1_trajectory_native_gs_20261113/report.md)。

## 模糊提取器可以保证什么

标准定义为`Gen(w) -> (R, P)`和`Rep(w', P) -> R'`。其中P是恢复辅助数据，R是提取结果。论文明确只保证距离不超过t时恢复R；超出t时对输出没有保证。因此，严格拒绝边界还需要限定距离的恢复、恢复后距离检查，以及密钥确认/认证；不能把普通译码器输出任意码字当作认证成功。[Dodis等，SIAM Journal on Computing 2008，定义3](https://www.cs.bu.edu/~reyzin/papers/fuzzy.pdf)

该论文的密钥均匀性依赖输入在辅助数据及对手信息条件下仍有足够的最小熵。1024位长度、逐位接近均衡或低样本相关性，均不构成1024位密码学熵。公开图像和公开码器使内容本身可读，因此内容提取结果不能单独充当提供者秘密。需要另有提供者主密钥，并对用途、版本、图像身份和随机盐作分域；具体构造仍须证明，不能用一次HMAC调用替代完整安全论证。

P必须有可定位且经过认证的存储位置。若它放在需要R才能读取的同一水印中，会形成验证循环；若使用外部记录，则需报告记录容量、查询方式及多记录搜索的整体误报预算。相近内容重复注册还涉及辅助数据重复发布，普通模糊提取器不自动具有可重复使用安全性。[Canetti等，Reusable Fuzzy Extractors for Low-Entropy Distributions](https://par.nsf.gov/servlets/purl/10092290)

“载体源码不变”还需要通过原生密钥接口实现。PRC应继续使用其原生KeyGen与编码/检测过程，记录每图密钥生成成本；不能把任意派生矩阵当作原生PRC密钥。内容条件化密钥、每图密钥和多记录检索改变了协议假设，原载体的固定密钥FPR或不可检测性结论不能未经检查直接继承。

## 1e-6不是密钥长度的直接结论

必须分别测量：

1. 无水印图在完整验证器下的误报，以及错误身份/错误密钥下的接受；
2. 不属于目标记录的图进入内容恢复区域的概率；
3. 超出恢复区域的错误译码、认证或密钥碰撞；
4. 已发表伪造基线在完整系统下的接受。

`2^-128`最多描述满足相应假设的密码学事件，不能代替第2或第4项。只有在独立公平比特模型下，随机1024位码落入固定汉明球的概率才是`2^-1024 * sum(C(1024,j), j=0..t)`；当前学习码、同提示词样本和攻击输出不满足已经证明的该模型。载体和内容判定也不能未经证明直接相乘。证明目标应是明确条件下的整体上界，经验结论则使用冻结的独立null及完整检测链路。

纠错还应区分“任意t位错误都可恢复”与“某个随机错误模型下高概率恢复”。不能把随机信道容量当作对任意语义漂移的恢复保证。较大纠错半径还会增加辅助数据长度、降低可提取熵。

## 生成时序与实例训练必须同时成立

现有辅助图路线是`辅助图码 -> 内容密钥 -> 原生载体 -> 最终图码`。改变载体密钥通常改变生成实例；载体实现不变，并不保证辅助图与最终图的实例内容相同。若训练明确排斥同提示词下的不同实例，同时又要求最终实例恢复辅助实例的密钥，就会产生目标冲突。

从最终图直接派生生成前的载体密钥则存在因果循环。可比较的部署路线如下：

| 路线 | 需要解决的事实 | 贡献边界 |
|---|---|---|
| 生成前由内容派生原生载体密钥 | 在保持原生GS/PRC生成的同时，得到足够接近最终发布实例的预先内容参考 | 最符合原设想，但当前未解决自洽性；重复生成并筛选成功者不能掩盖失败率和成本 |
| 原生随机密钥生成后，用最终图内容封装该密钥 | 已生成图像有确定身份；恢复辅助数据、封装记录与提供者认证需另行存储并定位 | 能避开辅助图漂移；属于有记录的密钥封装/认证协议，不能称完全无状态、生成前内容派生 |

第二条路线需用经过审查的密钥封装构造，并保留提供者秘密；仅用公开内容可恢复的R加密载体密钥会暴露该密钥。它还必须与“原生载体检测 AND 相同实例指纹的固定阈值匹配”比较。若相同信息权限下二者接受集合等价，模糊提取器的贡献在协议或存储性质，而非额外防伪能力。

## 训练方向与可检验机制

方向2可以承担核心表征问题：同一发布图的允许编辑应留在恢复区域内，其他实例应位于区域外。训练应直接针对恢复半径的内外间隔与合法编辑尾部风险，而不只追求平均对比损失。

训练标签必须相对于具体来源记录。另一张由提供者合法发布的图可对自己的记录有效、对当前记录不匹配，不能全局当作“伪造”。已发表攻击输出只有在满足明确定义的身份/内容改变条件时才是相应负例，不能仅按执行脚本名称贴标签，以免学习处理伪影。只能调用既有发表攻击，不修改算法或开展攻击搜索。

训练、校准和测试按原始图/提示词族分组隔离；已查看的100提示词仅作开发诊断。评测分别报告合法编辑保留、同提示词实例区分、完整Imprint/Reprompt接受、自然null、算力和辅助数据成本。训练中使用的攻击与测试泛化范围必须明示。

增强视图作正例、不同实例作负例已有成熟先例，例如[SSCD，CVPR2022](https://openaccess.thecvf.com/content/CVPR2022/html/Pizzi_A_Self-Supervised_Descriptor_for_Image_Copy_Detection_CVPR_2022_paper.html)。因此“换正负样本＋模糊提取器”本身不足以支持创新性。研究贡献应落到生成身份自洽、恢复区域的可验证分离，以及相对简单内容匹配的独立收益。

## SemBind的部分绑定假设

[SemBind最终论文§4.1](https://proceedings.mlr.press/v306/zhang26hj.html)确实对GS/TR使用sigma=1，对PRC/GS++使用sigma=0.5；其训练同时含同提示词聚类和良性增强一致性，不能叙述为没有训练良性鲁棒性。

在符号掩码模型中，设两个语义码的差异比例为q，均匀覆盖下进入载体的符号差异比例约为sigma*q。若q约0.5而sigma=0.5，则约25%坐标有符号差异。这是机制假设，不是译码后BA或攻击成功率；PRC软译码、GS++纠错、反演误差和语义相似性均会影响最终结果。

验证应在同一载体、语义网络、数据及原发表攻击上比较sigma=0.5与1，分别给出绝对合法接受和攻击接受，并检查语义差异、进入译码器的误差与译码结果之间的关系。若sigma=1已解决问题且合法性能相当，新的密钥协议必须说明额外收益。尚未有这些配对实验，不能将残留成因写成结论。

## 研究优先级

优先验证最终发布实例的鲁棒指纹，并解决内容参考与载体生成的时序；之后再验证经过认证的密钥恢复是否提供超出直接距离门控的收益。原生基线复现和匹配工作点继续完成。方向3暂不合入主方法：裁剪会同时造成实例信息丢失、坐标不确定和载体反演失配，估计坐标系本身不保证修复后两项。

内容依赖密钥与几何归一化已有长期研究，例如[Lu，Signal Processing: Image Communication 2005](https://www.iis.sinica.edu.tw/papers/lcs/1744-F.pdf)；容错认证亦见[Juels与Wattenberg，CCS1999](https://www.arijuels.com/wp-content/uploads/2013/09/JW99.pdf)。这些文献不等价于当前扩散方案，但限定了“首次组合”的可主张范围。当前检索未建立穷尽性查新结论，也不据此保证会议或期刊录用。
