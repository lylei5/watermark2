# 实例条件密钥恢复

目标：从经过合法处理的最终发布图中，实际恢复同一把128位绑定密钥，再解封该图原有的水印验证材料。生成时沿用原生载体；生成结束后登记最终图，避免以尚未生成的最终内容决定生成密钥的循环。

已经完成[可靠选位与码陪集](../reports/instance_coset_recovery_20261113/report.md)、[编辑状态选位](../reports/instance_edit_code_20261113/report.md)和[连续编辑方向恢复](../reports/instance_edit_quotient_20261113/report.md)三轮实验，每轮14760次真实解码。当前八方向版本的合法恢复为473–477/500、不同实例0/50；共同校准目标及多模板SSCD比较见最新报告。恢复出的材料已经送入原作者GS检测函数，完整链路可执行。

## 连续编辑方向恢复

设最终图的单位特征为f，登记视图为v_j。以`v_j - (v_j^T f) f`形成该实例的编辑方向，用四个处理类别的均值或全部八张视图得到正交基U_i。定义`P_i=I-U_i U_i^T`，登记与查询均先计算`normalize(P_i f)`，随后选位、BCH绑定和恢复。P_i保留参考方向，减少登记编辑在量化前的扰动。

U_i以float16存储并在使用时重新正交化。恢复函数从认证记录读取U_i，对查询执行相同变换；原图特征只在登记与单独的精确区域对照中使用。八方向紧凑辅助字段9408字节，四方向5312字节；二者均包含码偏移、掩码、确认与MAC，原生材料封装另计。

这一构造与[切空间距离，NIPS1992](https://papers.nips.cc/paper_files/paper/1992/hash/26408ffa703a72e8ac0117e74ad46f33-Abstract.html)相关。当前证据是实际恢复区域及其配对实验；独立的论文创新需要由更稳定的效果、协议性质或成本优势建立。相同变换的连续SSCD已纳入强对照。

## 完整流程

1. **登记编辑响应。** 对最终图提取512维SSCD特征，同时用GS官方实现产生裁剪、随机丢弃、加噪和椒盐四类处理，各两张登记视图。九类正式查询使用另外的随机种子；亮度、JPEG、模糊、中值和缩放五类没有进入登记视图。
2. **确定实例码。** 在全局随机投影池中选择1023位。普通对照按干净图投影裕量选择；实例条件版本按该图八张登记视图的投影变化归一化裕量。这一步属于已有可靠位选择思路的实例化。
3. **构造编辑子空间。** 记最终图码为b，四类登记视图各自的平均特征对应码为b_j，保存四个变化向量B_j=b_j XOR b。候选恢复区域允许这些变化向量的二元线性组合，再由BCH纠正剩余错误。
4. **绑定和封装。** 将128位密钥κ加5个固定零位后，用BCH(1023,133,d≥255)编码为C(κ)。辅助记录保存b XOR C(κ)、选位掩码、四个变化向量和密钥确认摘要。原生水印材料使用由提供方秘密和κ派生的AES-GCM密钥封装；全部辅助字段另用HMAC认证。
5. **实际恢复。** 查询图产生码q。验证器依次对`q XOR offset XOR B a`进行BCH译码，核对κ摘要和距离，再解封原生材料。恢复函数的输入只有查询特征、辅助记录、全局投影和提供方秘密，没有参考图特征或参考码。

代码入口为[instance_coset_recovery.py](../scripts/defense/instance_coset_recovery.py)。登记接口默认使用独立的密码学随机κ；配对评测为各方法使用相同κ，依据私有提供方秘密、重复编号和记录ID产生伪随机128位值。恢复函数没有调用该评测派生过程。身份材料、提供方秘密、投影随机种子、辅助记录均保存在249的private_eval，Git记录协议与哈希。

## 方法所检验的机制

统一汉明球把所有错误同等对待。本候选把同一实例中反复出现的编辑变化交给一个低维子空间表示，让BCH处理余下的错误。恢复集合为：

`R_i = {q : min_a Hamming(q, b_i XOR B_i a) <= 127}`。

至多四个变化向量对应至多16个陪集。实验已比较干净裕量固定BCH、编辑裕量固定BCH、仅五个登记中心的模板恢复和完整陪集恢复。在两轮已执行配置中，陪集组合均未增加模板恢复之外的成功样本；全部错误实例与已有Imprint输出均计入评测。

这是一种实例条件码设计候选。码偏移、BCH和可靠位选择分别有既有基础，研究贡献要由编辑结构的作用与完整比较结果建立。

## 公平对照和协议边界

直接SSCD单参考、九个登记视图的多模板SSCD、存储为int8的多模板SSCD，都使用相同最终图和登记视图。另设同投影、同编辑偏移的精确汉明区域对照。

对于正确的有界距离译码器，确认正确κ后的接受集合与上述精确区域一致。因此，密钥恢复本身的收益是实际解封能力；防伪和鲁棒性收益应来自区域构造。实验逐条核验真实译码与精确区域是否一致，随后报告各方法在共同合法检出率下的误接受以及辅助记录开销。比较时将所有恢复失败保留在分母中。

提供方秘密用于记录认证和封装，图像本身不是秘密。本实现不把128位密钥长度解释成128位内容熵，也不把摘要碰撞概率解释成伪造图误接受率。选择掩码和编辑向量的信息泄露、多个登记记录的联合泄露仍需独立分析；当前是经过认证的内容门控密钥绑定原型。

实验数据包含100个原空间GS来源和10个PGID原生GS来源。前者测内容恢复与同提示词不同实例；后者复用完整151更新Imprint和已有反演，测试对原生验证材料的恢复与联合判定。两个GS实现分开报告。新的码器训练、攻击生成和载体修改都不在本轮执行内容中。

## 相关工作边界

- [A Fuzzy Commitment Scheme，CCS1999](https://doi.org/10.1145/319709.319714)：码偏移和容错开启是已有密码学构造。
- [Quantization in zero leakage helper data schemes，2016](https://doi.org/10.1186/s13634-016-0353-z)：可靠分量选择、引导量化和辅助数据泄露已有系统研究。
- [Subspace Fuzzy Vault](https://arxiv.org/abs/1210.7190)：在子空间码上构造模糊保险箱；本候选以图像编辑的二元差分扩展固定BCH码的候选集合，不能仅凭使用“子空间”主张新密码学原语。
