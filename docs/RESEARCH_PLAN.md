# 防御研究计划

目标是在合法检出率、图像质量、信息权限及计算预算可比的条件下，建立有独立证据支持的防御改进。目前没有已确认的原生 SemBind 优越性结果。

## 当前科学结论

[完整结果索引](../reports/README.md)记录各轮失败及对照。共享语义评分降低了实际合法接受；生成端反馈、分位载体、最小反射、条件传输和连续语义区域均未通过各自冻结门槛。语义预测精度、预览 LPIPS 或潜变量距离的改善，不能单独作为认证改善的证据。

最新载体研究的[连续区域筛选](../reports/continuous_geometry_screen_20261113/report.md)已完成，只有干净图结果。当前执行[第一阶段协议](PHASE1_PROTOCOL.md)：原GS载体基线、检测工作点与轨迹语义观测；运行状态见project_state.json。

## 下一阶段验收顺序

1. **完成原生基线审计与复现。** 将官方完整生成、绑定、反演、验证流程及参数逐项对应到执行代码；明确私有材料、语义预处理、检测阈值及理论和经验 FPR。现有 DPM 组件适配不能替代该项。
2. **定义可比较工作点。** 同一来源划分、合法编辑条件、完整发表基线预算；比较绝对合法检出率、错误身份及自然负例、伪造接受、图像质量与计算成本。不筛掉失败的合法参考。
3. **提出一个有机制对照的防御假设。** 从已保存的失败结果说明要改变哪一种误差，以及为何简单控制不能解释收益。软译码、语义投影、分块、旋转或条件采样本身均不自动构成创新。
4. **冻结后独立验证。** 新方法、阈值及数据划分在看确认结果前固定。已使用来源只能作开发或诊断；扩大研究须有真实证据，不预设更好结果。

在原生基线范围和工作点明确之前，暂缓扩展候选方法。实验执行状态只维护在[project_state.json](../project_state.json)，冻结实验计划保留为出处证据。

方向A的[查新审查](PHASE1_NOVELTY_REVIEW.md)已发现中途语义水印与同轨迹后期绑定的直接先例；观测门槛通过也不等于创新性或防御成功。

## 计算与评测约束

只使用顶会顶刊已发表攻击的既定实现和完整预算；不得创造或改进攻击。CPU/GPU 实验均在 249 执行，仅用空闲 GPU 7、5、4，最多三张，始终排除 GPU 6。通过进程退出事件接续已经冻结的任务，不持续轮询。模型、图像和私钥留在服务器，代码和证据同步到 main。
