# 防御研究计划

目标是在合法检出率、图像质量、信息权限及计算预算可比的条件下，建立有独立证据支持的防御改进。当前已完成真实实例密钥恢复和多轮强对照，新的论文主线仍需通过机制与效果检验。执行状态只维护于[project_state.json](../project_state.json)。

## 当前证据

[PGID合法图对照](../reports/recovered_carrier_transfer_20261113/report.md)已收齐，完整预算Imprint与TR/PRC合法数据可配对比较。PGID合法TR60/100、PRC29/100；原生分别100/100、64/100。相同合法通过数下的内容门控、实例恢复和原生PGID结果单独呈现。

[共同频谱恢复](../reports/shared_channel_binding_20261114/report.md)完成17040次真实恢复与690次配对消融。共同相位的TR最大恢复仅19–21/100，同码器SSCD83–84/100。完整频谱改善普通实例区分，仍接受大量Imprint。合法编辑在VAE与反演链中缺少稳定的共同响应，这是当前机制的主要失败点。

[CopyNCE作者模型](../reports/copynce_control_20261114/report.md)提供了比单一SSCD更全面的强对照。匹配器在冻结GS95%点联合通过TR98/100、PRC59/100；SSCD为98/100、64/100。五类编辑逐类排除校准后，匹配器内容判断TR/PRC各50/50，所有对应阈值下已有完整Imprint均拒绝。其完整参考图输入和配对推理成本需要计入。

## 下一机制的研究问题

研究重点是限定登记信息与查询成本后的实例恢复区域：查询中的哪种观测能容纳合法编辑，同时保留其他实例和伪造图的差异。局部匹配、几何不变量、模糊金库、可靠位选择和编辑估计结合译码已有直接先例。候选需要新增可检验的区域构造或协议性质，并与成熟配对匹配正面比较。[机制说明与查新](INSTANCE_BINDING_RESEARCH.md)给出具体依据。

按以下顺序推进：

1. 写清观测、实例约束、恢复输入和秘密边界，给出直接门控、普通校正及成熟匹配的对应控制。
2. 冻结同来源校准与编辑类型留出规则；先验证连续实例间隔，再运行实际密钥恢复和原生检测。全部合法参考进入分母。
3. 在相同绝对合法通过数下报告同提示词实例、错误记录、普通负图和完整已发表攻击；同时列出参考存储、辅助数据、原生材料与查询成本。
4. 有开发证据后，在新来源上冻结并执行确认；已观察数据继续作为开发证据。真实恢复正确性和经验误接受率分别验收。

SemBind、PGID、SEAL继续按[三个原生基线契约](THREE_BASELINE_REPRODUCTION.md)补齐各自完整矩阵。SemBind未公开部分按用户授权由论文补齐并标明差异；原生工作点对齐是后续总体优越性比较的条件。本轮完整攻击范围为Imprint，Reprompt及全部论文矩阵仍单独待验收。

## 计算与评测约束

只使用顶会顶刊已发表攻击的既定实现和完整预算，不创造或改进攻击。CPU/GPU实验均在249执行，仅用空闲GPU7、5、4，最多三张，始终排除GPU6。通过进程退出事件接续冻结任务，不持续轮询。实验运行期间进行方法研究、查新和结果审计。模型、图像和私钥留在服务器，每完成一项代码、协议、结果与当前说明同步到main。
