# 防御研究计划

目标是在合法检出率、图像质量、信息权限及计算预算可比的条件下，建立有独立证据支持的防御改进。当前已完成真实实例密钥恢复和多轮强对照，新的论文主线仍需通过机制与效果检验。执行状态只维护于[project_state.json](../project_state.json)。

## 当前证据

[部分序恢复与未见编辑验证](../reports/order_capsule_confirmation_20261115/report.md)完成11400次部分序解码、7552次精确密钥及认证载荷返回。主设置在100来源已知条件上返回993/1000，噪声95/100、六倍亮度98/100。恢复后不再使用图像残差门槛；同α前向密钥对照为935/1000，旧α0.3精确密钥为963/1000、最终返回894/1000。各差异分别报告，避免把门槛移除与解码改进混为一个因素。

同已知合法993/1000时，九模板SSCD误收同提示词其他实例18/100，恢复和直接部分序拟合均0/100。新方法相对直接参考的独立判别、存储与隐私优势仍未成立。未见对比度500/500，旋转3/500、裁剪后缩放18/500；来源图曾用于项目，编辑类型在冻结前没有参与开发或效果查看。

[饱和贡献消融](../reports/order_saturation_ablation_20261115/report.md)完成400次实际解码。保留或删除纯白坐标，亮度98/100和噪声95/100逐例相同。亮度新增28例对应前向对照的坐标不足，说明剩余关系可以绕过固定先导位置的拟合限制；保留饱和比较本身没有显示额外收益。[完整开发攻击](../reports/order_capsule_development_20261115/report.md)中TR合法99/100，Reprompt+两代理0/10、1/10，直接参考拟合各0/10。当前恢复关系仍不足以作为完成的论文贡献。

[PGID合法图对照](../reports/recovered_carrier_transfer_20261113/report.md)已收齐，完整预算Imprint与TR/PRC合法数据可配对比较。PGID合法TR60/100、PRC29/100；原生分别100/100、64/100。相同合法通过数下的内容门控、实例恢复和原生PGID结果单独呈现。

[共同频谱恢复](../reports/shared_channel_binding_20261114/report.md)完成17040次真实恢复与690次配对消融。共同相位的TR最大恢复仅19–21/100，同码器SSCD83–84/100。完整频谱改善普通实例区分，仍接受大量Imprint。合法编辑在VAE与反演链中缺少稳定的共同响应，这是当前机制的主要失败点。

[CopyNCE作者模型](../reports/copynce_control_20261114/report.md)提供了比单一SSCD更全面的强对照。匹配器在冻结GS95%点联合通过TR98/100、PRC59/100；SSCD为98/100、64/100。五类编辑逐类排除校准后，匹配器内容判断TR/PRC各50/50，所有对应阈值下已有完整Imprint均拒绝。其完整参考图输入和配对推理成本需要计入。

[Reprompt+与实际恢复](../reports/reprompt_plus_recovery_20261115/report.md)完成240张完整候选预算输出、480条唯一原生/PGID判定和960次密钥恢复。TR合法95/100时，三尺度规则接受8/10、7/10，同合法SSCD各1/10。可观察选择在全部240张候选上与固定交集相同。当前路线已经具有可复核的实际恢复链路，新的证据关系仍需解决实例混淆。

## 下一机制的研究问题

研究重点是空间对应不确定时的实例恢复条件，以及信息删失后密钥的可辨识性。部分序求解已经说明不估计绝对亮度也能恢复，但它依赖固定坐标，未知几何编辑表现差。完整参考验证器可模拟任何使用同等信息的恢复器；独立价值需落到可量化的信息存储、密钥访问目标或不同资源约束下的恢复能力。局部匹配、几何不变量、模糊金库、可靠位选择和编辑估计结合译码已有直接先例。[最新查新](ORDER_CONSTRAINED_RECOVERY.md)及[机制说明](INSTANCE_BINDING_RESEARCH.md)记录依据。

按以下顺序推进：

1. 写清观测、实例约束、恢复输入和秘密边界，给出直接门控、普通校正及成熟匹配的对应控制。
2. 冻结同来源校准与编辑类型留出规则；先验证连续实例间隔，再运行实际密钥恢复和原生检测。全部合法参考进入分母。
3. 在相同绝对合法通过数下报告同提示词实例、错误记录、普通负图和完整已发表攻击；同时列出参考存储、辅助数据、原生材料与查询成本。
4. 有开发证据后，在新来源上冻结并执行确认；已观察数据继续作为开发证据。真实恢复正确性和经验误接受率分别验收。

SemBind、PGID、SEAL继续按[三个原生基线契约](THREE_BASELINE_REPRODUCTION.md)补齐各自完整矩阵。SemBind未公开部分按用户授权由论文补齐并标明差异；原生工作点对齐是后续总体优越性比较的条件。已完成既定来源上的完整Imprint、GS/TR/PRC两代理basic Reprompt及GS/TR两代理Reprompt+预算；论文规模的多来源、多目标与三防御完整矩阵分别验收。

## 计算与评测约束

只使用顶会顶刊已发表攻击的既定实现和完整预算，不创造或改进攻击。CPU/GPU实验均在249执行，仅用空闲GPU7、5、4，最多三张，始终排除GPU6。通过进程退出事件接续冻结任务，不持续轮询。实验运行期间进行方法研究、查新和结果审计。模型、图像和私钥留在服务器，每完成一项代码、协议、结果与当前说明同步到main。
