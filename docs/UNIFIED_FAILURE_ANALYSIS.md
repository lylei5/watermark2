# 统一对比的逐攻击失败分析口径

本文冻结需要保存的证据和解释边界，不提前填入未完成的攻击结果。准确率与成功率只使用主表共同来源、冻结工作点、完整作者预算的结果；历史小样本另列，不混入主表。攻击出处、权限、配置缺项见[适用性清单](UNIFIED_BENCHMARK_APPLICABILITY.md)。

## 每格先报告什么

每种防御、载体、代理/目标模型权限、攻击预算、工作点分别报告：独立来源数、成功生成候选数、完整预算完成数、自然图验证FPR与95%区间、干净图TPR、逐失真TPR、攻击后接受率、图像质量与计算成本。无防御与防御处理相同发布图时保留配对决策；SemBind/SEAL自身嵌入输出以共同提示词来源配对，不能称为同像素。

伪造主统计是完整预定候选集合中“任一候选被接受”的来源比例，同时公布逐候选结果。不能用更多候选扩充样本量，也不能在本项目新增候选排序、优化或筛选。去除统计是攻击后检出率，同时记录内容保留与失真。攻击生成失败、正常图生成失败和防御拒绝是不同事件，不把技术故障填成防御成功。缺少作者配置、不支持载体、未运行和执行失败分别标记。

## 按防御保存的证据

| 防御 | 保存的中间证据 | 可以据此判断的范围 |
|---|---|---|
| SemBind | 生成辅助图与最终图的语义码；查询语义码；反演噪声；查询码解绑定后的原载体分数；辅助码解绑定的诊断分数 | 区分内容码漂移伴随的拒绝与载体恢复不足。辅助码分数只作诊断，不替代无状态检测规则。语义码变化和误收相关不自动构成因果证明。 |
| PGID-F/R | 同一输入的原始反演与PGID反演噪声、原载体连续分数、两种固定PGID配置的完整调用预算 | 明确防御修复/破坏了多少合法判定，以及改变了多少攻击判定。不得依据攻击类型在F/R之间挑最优，也不能只凭少量Reprompt误收声称“原理上不可能防住”。 |
| SEAL | 预览/最终/查询caption；内容派生参考噪声；反演噪声；1024块原距离；候选自身caption的匹配块数 | 区分参考变化与反演误差。已知原始嵌入噪声的评分是额外信息诊断，不能作为SEAL无状态成绩。空间定位热图与语义验真分别报告。 |
| 原生载体AND登记SSCD | 原生分数、候选与该登记图的连续SSCD分数、完整联合判定、登记索引和存储量 | 量化逐图参考提供的增益与合法损失。它需要状态，不据此证明无状态方案一定无法达到同样性能，也不称理论上限。 |

## 按攻击检查的失败模式

| 已发表条件 | 预先固定的检查 | 报告时避免的误判 |
|---|---|---|
| Imprint-F | 原作者最终151次更新；另列51/101次检查点。比较载体分数提高是否伴随SemBind/SEAL内容参考不一致，PGID是否改变原本接受的判定。 | 最终预算与早期检查点分开；防御低合法TPR不能包装成强伪造防御。 |
| Imprint-R | 原作者完整151更新；比较攻击后原生TPR与PGID-R恢复量，并测攻击图失真。 | 不把所有攻击后拒绝都视为质量合格的成功去除；不使用PGID-F/R逐例择优。 |
| Basic Reprompt | 保持原作者反演/重新生成与提示词规则，分别统计代理模型；保存内容变化与载体分数变化。 | 保留下来的噪声相关性是待测因素；不能预设全部防御共同失败。 |
| Reprompt+ | 原GS9候选、TR3候选；公布来源层任一接受与逐候选分布。 | 不把9倍候选数当9倍来源；不改重采样布局，不新增PRC扩展。 |
| SEAL目标模型重新生成伪造 | 目标模型权重可访问条件单列；比较查询caption派生参考与原始嵌入噪声的诊断关系。 | 不能并入仅代理模型的Reprompt，不能据额外目标权重权限跨列排名。 |
| Cat Attack | 按作者随机对象、比例、位置规则；语义接受与空间定位分别统计，记录真实编辑区域。 | 空间AUC不是固定FPR下的语义检测率；不新增对象或位置搜索。 |
| Averaging/Steganalysis removal | 按原公布辅助样本预算及配对/非配对权限分别统计；辅助数据与500主来源隔离。 | 不把高预算配对灰盒结果并入少量样本黑盒结果。 |
| Regeneration removal | 原去除模型与公开预算验收后，检查水印检出损失与内容质量；与重新生成伪造单列。 | 配置未核清时记缺项，不按名称猜参数。 |
| WMCopier | 取得原作者对应载体配置后按完整辅助数据与训练预算执行；训练数据隔离。 | 1000图/10000步和5000图/20000步分别列明；无配置不伪造可复现结果。 |
| WAVES常规失真 | 使用共同作者函数、冻结强度、随机种子；记录各防御逐类合法损失及配对差值。 | 常规编辑导致的合法拒绝是防御代价，不称为阻止伪造。 |

共同薄弱点的结论要求：同一已发表攻击条件下，各防御都完成配置验收、全预算运行、共同工作点与独立FPR验证，并且各自绝对合法TPR可见。若未满足，仅陈述已完成格子的观察；未支持和未执行的格子不参与“共同失败”判断。

## 统计和解释

逐条件比例给出来源层95%二项区间；方法差值与跨编辑汇总按来源配对、按数据集分层重采样。500来源的功效取决于配对不一致率；不以总查询数承诺任何差异都可检出。正式显著性结论还需要在全协议中固定主要对比及多重比较处理。

结果文字分开写“直接观察”“与机制一致的解释”“尚不能排除的因素”。例如，若同一合法图的候选参考评分失败、原嵌入参考评分通过，可描述为参考变化相关的失败；该诊断仍不等于已经完成独立因果干预。不会为解释失败而设计或增强攻击。
