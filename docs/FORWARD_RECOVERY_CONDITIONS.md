# 前向恢复区域的成立条件

本说明给出已实现原型的数学范围，配套[开发集结果](../reports/transported_capsule_observability_20261115/report.md)。其用途是分清图像分离、可恢复性和密码认证分别由什么条件保证。

## 查询如何决定恢复区域

登记观测x与随机128位符号向量s形成辅助记录`h=x+αBs`。查询y先确定可用坐标S，再由未编码的先导区域估计共享编辑`Â,b̂`。定义：

`D = αSÂB`

`r = S(Âx+b̂−y)`

`v = S(Âh+b̂−y) = Ds+r`。

若D满列秩，最小二乘解为`s̃=s+D†r`。充分条件`||D†r||∞<1`保证逐位符号恢复；这是对该查询、该编辑估计、该观测集合的条件。直接充分界`||r||₂/σ_min(D)<1`较保守，但清楚展示信息损失与噪声放大之间的关系。

满列秩保证唯一实值解。有限的±1码字集合可能在秩不足时仍可区分；当前求解器没有实现这类离散译码，因此实验中的秩拒绝属于算法范围，不是所有编码方案的不可恢复性结论。

当查询被裁剪或部分饱和，S和D都会变化。方法由查询的观测关系产生恢复区域，区别于先给定一个固定嵌入空间的球。但随机基函数、实值码偏移和条件数分析本身都是已有工具，新颖性仍需要与联合编辑估计/译码文献作进一步对应。

## 检查残差与直接参考的关系

解出正确s后，未参与译码的坐标V上有：

`αVÂBs − V(Âh+b̂−y) = V(y−Âx−b̂)`。

因此该残差核验与直接参考图前向拟合等价。采用相同坐标选择和编辑估计时，封装最终接受集合是直接参考残差接受集合与密钥可恢复集合的交集。它可以进一步拒绝某些图，也可能丢失合法图；独立增益需在同合法覆盖下由实验给出。

目前TR95/100工作点下，两者对已有Reprompt+均0/10。这支持共享编辑关系的图像判别作用，未显示密钥可恢复集合额外改善攻击区分。

## 顺序统计量处理了什么

若g单调不减，第k顺序统计量满足`ord_k(g(x₁),…,g(xₙ))=g(ord_k(x₁,…,xₙ))`。原型使用8×8块的第32个值，使逐通道亮度截断在统计量前后保持一致；只在非饱和位置使用线性分支。区域均值通常不与截断交换。

空间模糊、几何重采样、块内遮挡与非单调编辑一般没有这个交换性质。当前方法用共享高斯混合近似它们，估计误差进入r。已经出现过的JPEG、中值、噪声等处理，即使不在算子族内，也属于开发已见类型；校准留出分析不能代替真正未见类型的确认。

## 密钥长度与内容安全

128位随机密钥、确认哈希、认证辅助记录和AEAD共同保护恢复值与记录完整性。图像误接受率由查询的恢复区域决定，不是2^-128。该服务端协议没有证明辅助数据对原图的隐藏性，也没有证明128位内容熵。

查询项移除消融中，分布式基函数的2/30记录仍能在持有服务端秘密时恢复密钥。这不涉及攻击者能力或最终图像接受；它说明当前码偏移在这些记录上没有形成不可替代的查询需求。继续强化密码层时，应明确希望保护的对象、谁持有辅助记录和基函数，以及真实查询提供了多少新增信息。

## 下一阶段的证据要求

优先保留“同一编辑应在分离区域产生一致解释”的判别关系，进一步检验其对未见类型和新实例的稳定性。密钥层的独立价值应表现为有定义的协议能力或同合法覆盖下的区域改进，而不能由精确返回次数替代。几何坐标变化、公开辅助信息安全、未见处理与大样本完整攻击分别设置验收，不合并成一个笼统的成功标签。
