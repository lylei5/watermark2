# 可观察证据约束下的实例恢复

本实验检验一个具体机制：粗结构与细节提供的实例证据不能互相抵消。若查询图仍保留某组细节，该组证据也必须支持同一实例密钥；只有可观察性规则判定其信息不足时，恢复器才可省略该组约束。原生水印载体保持不变。

## 已有结果提出的问题

上一轮可见性译码在TR合法图上恢复99/100，但对完整Reprompt仍接受8/10、9/10。它把局部亮度次序统一放进一个错误／擦除预算：粗结构提供足够一致符号时，重新生成的其他内容可能被纠错吸收。区域隔离又以较低合法覆盖换取拒绝。新实验因此固定图像、密钥、helper和码参数，单独比较恢复证据之间的逻辑关系。

## 冻结实现

从最终发布图建立三组观测：Gaussian σ8的粗结构、Gaussian σ4减σ8的中间细节、Gaussian σ2减σ4的较细细节。每组255个8位局部次序符号，位置覆盖17×15抖动网格，参考图的对比度裕量决定选位。三组各自用RS(255,16)绑定同一个随机128位密钥。helper认证、密钥确认及原生材料加密解封沿用已验证接口。

每组每个符号的可观察性，由查询中所选像素对差值绝对值的中位数决定。阈值固定为`max(0.5, 0.1×参考裕量)`；至少64个可见符号才激活该组。这里使用无符号强度，不使用攻击标签、目标提示词、参考符号的正负匹配结果或译码成功反馈。它是待检验的可观察性近似，灰度强度并不自动给出可靠编辑状态。

| 配对规则 | 返回密钥的条件 | 所检验的问题 |
|---|---|---|
| coarse | 粗结构译码成功 | 只有粗结构时的实例混淆 |
| any_scale | 任意一个激活组译码成功 | 多尺度择优是否扩大伪造接受集合 |
| all_scales | 三组全部译码成功 | 强制保留全部细节对合法恢复的损伤 |
| observable_scales | 粗结构成功，且每个激活的细节组也成功 | 可观察性是否能在合法缺失与实例变化之间保留区分 |

所有成功组必须确认同一密钥，解封后逐字节核对载体材料，并调用原作者检测器。三个译码候选在四条规则间共享，每个记录—查询的API判定为四次，实际RS尝试次数另外统计。比较不把重复规则计为独立图像或独立译码实验。

设每组可恢复事件为`R_l`，激活集合为`A(y)`。主规则的接受条件是`R_coarse ∩ ⋂_{l∈A(y)} R_l`。在固定观测下有：

`all_scales ⊆ observable_scales ⊆ coarse ⊆ any_scale`。

每个必需组仍需满足RS的`2e+s≤239`以及正确密钥确认。恢复成功对每组提供独立列出的代数证据；这不假设组间统计独立，也不提供视觉误接受率乘积公式。

## 实验验收

协议在读取本原型结果前冻结，使用此前770个记录—查询配对，共3080次恢复API判定。GS主要结果保留3个评估来源，TR/PRC各10个迁移来源。完整Imprint和basic Reprompt保持原样；另以原论文Reprompt+的固定9/3候选预算补充验证。合法图的既有置黑crop/drop与真正crop-and-scale分别说明。

主要比较是同绝对合法通过数下的攻击接受，强对照包括SSCD单参考、中心化、多模板float/int8以及作者CopyNCE描述子/匹配器。恢复正确性、规则包含关系、各组激活/失败率和原生联合通过逐条核验。必须同时看合法覆盖；仅扩大必需组数量而损伤合法覆盖，应归入严格门控的对照。

本队列已用于方法开发。五类未登记编辑也已被观察，属于登记外处理，不能再称独立未知编辑确认。有效候选需要新来源和预先冻结的新处理划分。

## 完成结果

[3080次实际恢复结果](../reports/observable_evidence_recovery_20261115/report.md)已完成。全部770个配对上，observable_scales与all_scales判定相同；TR合法95/100时，Reprompt仍接受4/10、6/10，对应SSCD为0/10、0/10。360项同合法通过数比较没有SSCD优势。当前实验支持“附加细节能收紧粗结构的接受区域”，可观察性选择的额外作用为零。继续研究需要先找到能真实区分合法证据丢失与实例替换的观测量，并在新来源、新编辑上冻结确认。
