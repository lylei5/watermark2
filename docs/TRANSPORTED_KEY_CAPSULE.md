# 随编辑前向变换的实例密钥封装

## 研究假设

现有实例恢复多在固定表征的邻域内纠错。多尺度实验中，丢弃约束会同时纳入重新生成图，细节交集又损失合法覆盖。这里检验另一种恢复关系：登记的密钥封装与密钥基函数经过同一个编辑算子后，仍应能解释查询图。

令登记图的低分辨率 RGB 为 x，128 位随机密钥对应 s∈{−1,+1}^128，私有基函数矩阵为 B，封装 h=x+αBs。若查询 y=A x+b+e，则

`A h+b−y = α A B s−e`。

因此恢复器可以在观察域解 s，无需求 A 的逆。A 即使丢失部分图像信息，只要保留的 AB 具有足够秩和条件数，仍可能恢复128位。无误差且A准确时，满列秩保证唯一实值解；有误差时，`||(αAB)†e||∞ < 1`保证逐位符号恢复。这个条件只证明给定线性观测模型内的正确性。

原型在封装的指定先导区域令 B=0，用这些区域拟合全图共享的处理规律。恢复用的区域与先导区域分开。解出位串后，用未参与位串拟合的区域检查同一处理规律的预测残差，再认证解封原生载体材料。参考图不作为查询恢复接口的输入；完整参考图仅用于同信息预算的直接对照和评估核验。

## 冻结原型

64×64 RGB、128位随机密钥、固定先导/译码/检查区域。低频DCT空间经私有正交混合并限制在非先导区域，α为0.1和0.3。比较恒等算子、先导估计前向算子，以及去掉检查区域残差约束的诊断。当前算子族为四个有限支持高斯核的非负混合与逐颜色通道偏移；饱和或置黑观测按冻结规则作为不可用坐标。只在先导区域拟合核权重，密钥在译码区域求解，检查区域计算残差。空间插值和饱和会造成模型近似误差，需由实验报告。

该模型不接收编辑类型标签。JPEG、噪声、椒盐和中值处理属于模型外检验；高斯核与线性亮度属于模型内关系。已有crop/drop为保留坐标的置黑图。本原型尚不解决裁剪后缩放或任意几何变换；未来几何处理须另设冻结实验。

阈值只由既有GS的30张合法校准图决定，90%和95%目标分别保存；密钥覆盖不足的点记为不可行。主要评估保留GS3来源/30合法图，TR、PRC各10来源/100合法图。使用已有完整Imprint、basic Reprompt和GS/TR Reprompt+，全部候选保留且逐张联合原生检测。

强对照包含六种既有SSCD/CopyNCE配置、相同先导估计下完整参考图的前向残差、同像素原始差异。必须区分：新的图像分离收益、从封装实际恢复密钥的能力、记录与计算成本。完整参考图的直接残差可以界定本机制的图像判别上限，已有强模型仍是主要效果对照。

## 安全与贡献边界

私有基函数由服务端秘密派生，辅助记录认证，解出的位串通过独立确认后用于AEAD解封原生材料。发布图与原生GS/TR/PRC载体均不修改。辅助记录并非已证明隐藏原图或具有128位内容熵的公开模糊提取器；其安全边界沿用服务端秘密与认证存储。给定真实发布图也能恢复该实例材料，这是绑定设计的预期行为。

如果去掉前向算子、检查区域或使用普通像素残差后效果相同，则没有证据将相应部分作为机制贡献。若实际恢复弱于完整参考残差，应如实报告解码损失。只有与直接参考方法和强内容对照公平比较后，才能判断该路线是否值得形成论文主线。

## 实际结果与可辨识性检验

[首轮完整实验](../reports/transported_capsule_20261115/report.md)完成3030次解码。三个设置仅恢复GS校准图20/21/22张，分母均为30，未达到预定覆盖。裁剪、区域丢弃主要造成有效秩不足；强亮度使先导观测缺失。

在正确密钥条件下，检查残差恰为`y−(Ax+b)`。683次返回的数值审计最大差1.74e-8。这一等价关系将机制评价分成两项：前向模型能否区分合法处理与实例替换；其条件下密钥封装能否以可控成本恢复。残差不是新增证据。

第二轮固定五个设置，只检验观测和求解条件：

- 在各空间位置分布随机平滑基函数，再正交化，检验局部区域保留时的可观察秩；与原DCT空间比较。
- 采用8×8块的第32个顺序统计量。对单调函数g有`order(g(x))=g(order(x))`，可保持亮度截断关系；与区域均值比较。空间滤波和块内遮挡一般不满足此等式，仍是模型近似。
- 仅使用至少24个先导观测且增益可辨识的颜色通道，同时要求128秩、256个译码坐标和256个检查坐标；与要求三个通道都可用比较。
- 恒等算子作为前向估计消融。全部设置α固定0.3，与首轮相同128位密钥长度和校准规则。

这些是恢复条件的实现与消融，均未单独登记为新颖性贡献。没有训练新特征、增加纠错外壳或改动发布图。[第二轮](../reports/transported_capsule_observability_20261115/report.md)实际完成5050次解码和317次恢复材料的原生检测。TR合法95/100时两代理Reprompt+各0/10，与九模板SSCD和直接参考前向残差相同。

[100实例迁移](../reports/capsule_source_transfer_20261115_v3/report.md)保持阈值与方法固定：主设置准确密钥963/1000，最终合法894/1000，同提示词不同实例0/100；SSCD单参考899/1000、0/100。当前主要瓶颈是强亮度丢失观测和噪声引起的残差拒绝，尤其噪声组已有100/100准确密钥但只通过45/100。形式化范围见[前向恢复成立条件](FORWARD_RECOVERY_CONDITIONS.md)。
