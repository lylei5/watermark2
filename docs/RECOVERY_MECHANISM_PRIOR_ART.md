# 实例恢复机制的文献边界

核查日期：2026-11-15。目标是找到能同时处理合法编辑与实例替换的恢复机制。当前多尺度实验已经完成实际密钥恢复；其收益来自增加细节约束，可观察性选择在 770 个配对及新增 240 张 Reprompt+ 候选上均没有改变判定。[完整预算结果](../reports/reprompt_plus_recovery_20261115/report.md)中，TR同合法95/100时原型接受8/10、7/10来源，SSCD各1/10。下表将可考虑的机制与直接先例对应，发表状态和本项目执行状态分别记录。

## 从现有失败得到的设计要求

纠错只能在已有观测上定义恢复集合。同一记录下，若合法图和伪造图在恢复器读取的全部观测上相同，确定性恢复器将返回相同结果。随机化恢复器的输出分布也相同。密钥长度和确认哈希解决的是恢复值的正确性；实例区分仍由观测是否区分图像决定。

本项目已经测过原生载体错误率、重复副本分歧和空间错误统计。[同维数对照](../reports/carrier_content_channel_20261113/report.md)中，通用潜变量均值/RMS的预测更好。因此，后续“载体提供编辑状态”的假设需要利用具体可辨识的变换关系，并证明它增加了通用统计所没有的信息。另一个已完成的[共同频谱实验](../reports/shared_channel_binding_20261114/report.md)表明，内容潜变量与反演噪声通常不能按同一编辑算子相消。

有向内容覆盖是值得保留的研究问题：裁剪可能删除参考图内容，而新查询中的可辨识内容应能由发布实例解释。它与只找一部分相似区域的任务不同。但 ASL 已明确研究编辑方向，模糊金库也已处理不定长集合；本项目需要进一步证明“完整查询证据的约束”带来新的恢复区域，而非把已有匹配分数接到密钥封装上。

下一候选的可执行验收应同时包括：预先固定的区域定义与实际密钥恢复、未参与开发的来源及编辑、同像素的连续匹配对照、同绝对合法通过率的原样完整预算攻击，以及存储/计算成本。若收益完全来自某个已知匹配分数，应归入该分数的对照结果。所有新查阅的攻击描述仅用于理解论文，本轮执行攻击始终为原作者 Reprompt/Reprompt+ 和既有 Imprint。

## 前向密钥封装的查新结论

[前向封装设计](TRANSPORTED_KEY_CAPSULE.md)补充核对了CCS1999模糊承诺、ASIACRYPT2006连续域secure sketch及S&P2016 PhotoProof。加性偏移、真实密钥恢复、编辑估计、许可编辑证明分别已有基础。候选的研究问题是从最终查询推断非可逆编辑后，在观察域恢复原生材料；PhotoProof则由编辑链主动携带证明，信息条件不同。

首轮3030次实际解码还确认：正确密钥后的检查残差与直接参考图前向拟合等价。这提供了必须加入的同信息对照，也排除了把残差检查单列为新贡献的依据。创新性仍需来自可检验的恢复区域或协议能力，并有未知编辑及实例替换下的优势支持；目前尚未建立。

补充检索到[DeepSignature](https://arxiv.org/html/2604.23016v1)，2026-04预印本。已读3.5–3.6和4.9：它先核验嵌入的内容编码及签名，再比较查询与认证编码的空间潜变量；作者明确讨论了每张图的鲁棒性和内容判别边界。因此，“精确恢复签名/密钥，再做内容一致性”已有清楚先例，本项目需要说明恢复关系带来了什么额外能力。此处只引用机制与限制，未将其作者性能数值作为本项目结果。

[RDIAS作者页面](https://maarab-sfu.github.io/publications/2025-RDIAS-number-3)标注ACM TOMM21(10),2025，摘要描述把鲁棒内容指纹嵌入图像并区分常见处理与内容修改。本次只核对作者摘要，尚未完成正文和作者代码的规格审查，不计为已复现基线。

未知编辑确认须区别三层：算子模型之外、阈值校准之外、整个开发过程之外。当前JPEG/中值/噪声可用于前两层分析，但这些类型已经参与本项目开发。后续真正未见处理可从[ICML2024 WAVES正式基准](https://proceedings.mlr.press/v235/an24a.html)选择并固定作者版本、参数和来源；不能用本项目自创攻击代替。仅做逐类阈值排除时，报告为校准敏感性分析。
