# 第三阶段冻结协议

主评价复用第二阶段的 24 张校准图和 40 张留出图。按登记图验证，各方法分别取 120 次合法编辑的第 114 个顺序统计量为阈值。Pilot 使用另 6 个提示词的 12 张归档图，MagicBrush 原有样本按行号交替取 12、27、47、89，颜色迁移取奇数编号。以 C 为预先指定的主要候选。如果它在 60 次 Pilot 合法编辑中通过至少 54 次，且比 A 多拒绝至少 2 个物体替换，才启动扩样。该门槛用于决定是否继续，统计推断以独立留出结果为依据。

扩样使用原定 40 张登记图及其供体、同词异种子，MagicBrush 另四个原有样本和 dev 行 128、135、136、141、151、155、169、177、180、184、190、195。这些首轮编辑仅按明确的物体替换指令预选。颜色迁移的偶数编号留作确认。对所有公开参照图重建五种合法编辑，检查评估域变化。外部样本阈值仍完全来自 SD2.1 校准集。区间按提示词或独立公开场景聚类；Pilot 样本单列。

复用已有 DINOv2-giant，不训练。所有输入完整画幅缩放至 224 平方并用模型的 ImageNet 通道参数归一化。登记两幅视图，即完整画幅和居中保留 50% 面积；每个查询只编码完整画幅，取两个登记视图中的较小距离。此几何先验覆盖协议中的已知中心裁剪。A 逐样本核对第二阶段单视图 4×4 RGB；B 用 CLS 余弦距离；C 将 16×16 patch 网格平均为 8×8 个区域，对应区域的余弦距离取最大的四格求均值；D 取 A 与 C 各除以校准阈值后的最大值，再独立校准。

E 在 C 的同一特征上按登记记录使用由 HMAC 派生的 64 维高斯投影，同钥核验。比较同维同分布的公开投影、另外四把实验钥、完整维数的正交等距变换，以及真正对应的图像用错误密钥的结果。实验密钥可复算，仅用于机制试验。不同图像的误收一律用正确密钥评分。空间消融用同一局部 token 的无序双向最近邻，以及区域均值池化；另报告仅完整登记视图和平均全部区域的结果。所有操作作用于既有图像，不生成新扩散图。
