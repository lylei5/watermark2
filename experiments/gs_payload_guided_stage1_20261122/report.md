# Stage 1：原生 256-bit Gaussian Shading 前向载荷绑定与扩散引导闭环验证

**核心结论：将预置目标特征直接写入原生 256-bit GS 载荷（保留 192–208 bit 身份位，载荷位自动继承 64× 空间重复），配合「中段 Jacobian-free Tweedie 引导 + 末段标准无引导 DDIM ODE」，彻底打破了此前不动点迭代 0/50 收敛的因果死循环。**
- 在导师原构想（`rgb48`）上，中段 Tweedie 引导全面优于 Phase 1 末端潜变量 Gauss-Newton：严格六项达标 **13/16 对 12/16**，LPIPS 降低 27%（**0.196 对 0.267**），且 **彻底消除 DDIM 反演退化**（干净 BA **1.0000 对 0.9924**，干净载荷 BER **0.00% 对 2.73%**，编辑载荷 BER **15.41% 对 19.70%**）。
- 在升级方案（`sscd64_mid_tweedie`）上，仅用 **64 bit（8 字节）无状态载荷** 实现：**干净盲验通过 16/16（BA 1.0000，载荷 BER 0.0000）**、**LPIPS 仅 0.088（CLIP 0.276 对无引导 0.277）**、**原生 GS 存活的全部四类 WAVES 0.8 强编辑（JPEG/1.8×对比度/亮度/噪声）端到端盲验通过 64/64（100%）**；对生成水印图实跑黑盒 **Reprompt 攻击** 时，**原生 GS 8/8 被攻破（auth BA 全 1.0000），本方案盲验 0/8 误收（100% 拦截）**。

## 补充验证（防对抗伪影、几何鲁棒性、实弹攻击与随机目标消融）

1. **几何鲁棒性（证明非脆弱对抗噪声）**：在 `sscd64_mid_tweedie` 生成图上对真目标 64-bit SSCD 测 `d_oracle`（门限 0.6951）：`compression 0.8` **16/16**、`resizedcrop 0.4` **15/16**、`resizedcrop 0.8` **14/16**、`erasing 0.8` **14/16**、`blurring 0.4`（半径 8）**14/16**、`rotation 0.4` **12/16**、`rotation 0.8` **11/16**；跨提示词 240 错配对仅误收 **3/240（1.25%）**。
2. **实弹黑盒 Reprompt 攻击（`reprompt_live_check.json`，8 组引导水印图）**：黑盒 50 步 DDIM 反演 + I2P 无关提示词重生后，原生 GS 认证位全部被攻破（**8/8**，BA 均为 1.0000），本方案 64-bit 盲验证全部拒绝（**0/8 误收**，平均距离 0.942 > 0.695）。
3. **纯随机 64-bit 目标消融（`random64_ablation.json`，4 提示词）**：跳过同词预览而直接给完全随机 64-bit 目标时，仅 2/4 能在编辑下保持达标（另 2 例 `d_clean = 0.687 / 1.120`，编辑后全面失败），说明「同提示词自然预览提取可行目标 + 中段流形引导」具有几何必要性，同时也说明无关图像无法轻易靠轻微流形扰动撞入任意目标锥。

## 诚实边界与下一步

1. 当前 Stage 1 为 16 个校准提示词的小规模机制闭环，尚未在 60–500 个独立留出提示词及 40,000 自然负例上建立完整论文主表，也尚未与原生 SemBind / SEAL / PGID 在共同工作点做大样本头对头对比；
2. 需在正式论文中明确讨论白盒自适应攻击边界（若攻击者白盒获取 SSCD 与投影矩阵 $P_{64}$），并建议把 $P_{64}$ 绑定发行方私钥（HMAC 派生每发行方私有正交投影）以防止公开特征空间定向优化；
3. 半径 16 极强模糊（19/120）与小区域局部物体替换（MagicBrush）仍是 64-bit 全局 SSCD 载荷的已知短板，后续可探索在 512-bit PRC 载体中组合 64-bit SSCD + 局部/空间统计。
